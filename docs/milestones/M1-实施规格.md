## T-1 SessionStream 正式化

`Mahjong.Core.Stream`：

```csharp
public enum StreamEventKind : byte
{
    Batch = 0x01,
    RoundStarted = 0x10, TurnStarted = 0x11, Drew = 0x12, Discarded = 0x13, Meld = 0x14,
    RequestOpened = 0x15, RequestClosed = 0x16, RoundEnded = 0x17, GameEnded = 0x18, SeatStateChanged = 0x19,
}
public sealed record StreamFrame(long Seq, long Tick, StreamEventKind Kind, ReadOnlyMemory<byte> Payload);

public enum StreamVisibility : byte { Seat, Spectator, Panorama }
public sealed class VisibilityPolicy
{
    public StreamVisibility Kind { get; }
    public byte Seat { get; } // Spectator/Panorama 为 255
    public bool CanSeeTileOf(byte ownerSeat);
}

public interface ISessionStream
{
    long LastSeq { get; }
    IReadOnlyList<StreamFrame> Drain(long fromSeqExclusive); // 增量
    IReadOnlyList<StreamFrame> GetFramesFrom(long seqInclusive); // 历史（重连/观战）
}
public interface ISessionRecorder { void Write(StreamFrame frame); void Flush(); }
```

- **事件 payload 唯一权威**：[M0.2 T-5 §1.1](M0.2/T-5-本地会话.md) 字段表；本任务只决定“流”的封包与可见性，不另造字段。Batch 的 payload = `frameCount u16 + (type u8 + payload)[]`。
- 可见性：座位流只给自己手牌的 tileId；观战为“无手牌玩家”；全景不过滤。**过滤在产出侧**，不是客户端过滤。
- seq 从 1 单调；Drain 后不重复；同 tick 事件合并为 Batch。
- 保留策略：每座位/观战/全景各保留本局全部帧；对局结束落盘后释放。M1 不做磁盘 spool。
- 本地单机也走同一 Stream（M0.2 `GameSession` 产出 SessionEvent → StreamFrame），避免两套。

## T-2 回放文件

- 严格实现 [replay-format](../specs/replay-format.md)（Header/Body/Index/Trailer 81B）。
- Writer：`ReplayWriter.Create(path, header)` + `Append(frame)` + `Close(index)`；reader 反向。
- 录制触发：`--record` 启动参数（单机/房主）或在设置中开启；路径 `ReplayPaths.Resolve()`：`MAHJONG_REPLAY_DIR` → `AppContext.BaseDirectory/replays` → 当前目录 `replays/`。
- 文件名：`ReplayPaths.BuildName(roomId, replayId, createdAt)`；单机 roomId=`local`、replayId=16 hex。
- 根 `.gitignore` 必须包含 `replays/`、`build/`、`bin/`、`obj/`。
- 校验：magic/version/长度/尾哈希；损坏抛可读错误；版本/内容哈希不匹配拒绝。
- 写入失败不阻断对局：记录错误并继续（回放是旁路）。

## T-3 回放播放器

- 复用 M0.2 的 `Table.tscn`（M0.2 T-6 拆出可复用桌面视图）；数据源从 `GameSession` 换成 `ReplaySource`。
- `ReplaySource`：`GetFramesFrom(seq)` + `FastForwardTo(tick)`；按 tick 驱动 Table 视图。
- UI：**8 局列表**（局号/赢家/分数变化）、播放/暂停、0.5–8x、±5s、±1 局、进度条。
- 拖动/选局 = 从 0 静默重放到目标 tick（不渲染），再继续；8 局重放 <200ms。
- 全景：强制所有手牌可见，标注“全景回放”；不显示操作按钮。
- 版本/内容不匹配置灰并提示；未完成（flags bit0=0）只播到最后完整局。
