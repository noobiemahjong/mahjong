# T-2 庄家计分（实施规格）

状态：见任务表
依赖：T-1
对应 master：[M0.3](../M0.3-规则完整化.md)
验收：L1 单测；§5 手算 12 例四座和全 0；`RoundStarted` 5B 金标重录。

## 1. 计分位与 API

本任务新增两位（其余五位归 T-3、T-4），取 `ScoreActionType` 未用高位，既有 1–64 只增不改。依据：[T-1 §4](T-1-规则表与数值定稿.md#4-事件协议回放字段总表)。

| 成员 | 值 | 本任务用法 |
|---|---|---|
| `DealerStreak` | 128 | 连庄奖励；单一位规则，赢家笔与三家 payer 笔同置 |
| `FollowingTheBanker` | 256 | 跟庄；单一位规则，赢家笔与庄家 payer 笔同置 |

- `ScoreManager.AllActionTypes` 同步并上两位，`KongActions` 不变；新位未进掩码时 `Apply` 抛异常且不改状态。依据：符号 `ScoreManager.AllActionTypes`、`ScoreManager.Apply`。

```csharp
// 伪代码：签名摘要，省略实现体，不可直接编译。
public void ApplyDealerStreak(byte bankerSeat, int bonus);                    // 庄家 +3*bonus，其余三家各 -bonus
public void ApplyFollowingTheBanker(byte winnerSeat, byte bankerSeat, int amount);  // 赢家 +amount，庄家 -amount
```

- 两段式约束：入口只写本局暂存（`RoundDelta`、`RoundActionType`），`Release` 才并入 `TotalScores`，`RollbackRound` 只清暂存。依据：符号 `ScoreManager.Release`、`ScoreManager.RollbackRound`。
- 校验先于写：座位不在 0–3 或 `bonus`、`amount` 为 0 时跳过记账且不置位，为负抛异常；两入口各自闭合，四座 delta 和恒为 0。依据：[scoring §3](../../subsystems/scoring.md)。

## 2. 连庄奖励

载体：`GameSession.RunGameLoop` 的 `bankerSeat` 旁新增 `byte dealerStreak`，同寿命同源；`RoundController` 不承载。依据：[DESIGN §5.7](../../DESIGN.md#57-轮次与庄家)。

状态机（取值先于 `EmitRoundStarted`）：

| 事件 | dealerStreak | 下一局庄家 |
|---|---|---|
| 第 1 局 | 恒 1 | 本局庄家 |
| 庄家胡（含抢杠胡） | +1，不封顶 | 不变 |
| 非庄胡 | 归 1 | = 赢家 |
| 流局 | 不变 | 不变 |
| 第 8 局 | 照常递增 | 无意义 |

金额：`bonus = dealerStreakBonus[min(streak, len) - 1]`，表 `[0, 1, 2, 3]` 表尾保持 3。依据：[T-1 §3](T-1-规则表与数值定稿.md#3-contentrulesjson-schema)。

| dealerStreak | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| bonus | 0 | 1 | 2 | 3 | 3 |

- 记账：庄家 +3×bonus、其余三家各 −bonus，两侧同置 `DealerStreak`；`bonus = 0` 不记账不置位；第 8 局照付、抢杠胡算庄家胡。依据：[T-1 §2](T-1-规则表与数值定稿.md#2-支付与叠加口径)。

`RoundStarted` 载荷 4B→5B，追加在末尾：

```text
RoundStarted = roundNo u8, bankerSeat u8, wallCount u16, dealerStreak u8   (5B)
```

- 同批改 4 处：`SessionEventPayloads.RoundStartedPayload`（加字段）、`SessionEventBuffer` 的 `EmitRoundStarted` 与 `EncodeRoundStarted`、`SessionEventPayloadReader.ReadRoundStarted`（4→5）、`EventPayloadGoldenTests`（现字节 `0x03, 0x02, 0x54, 0x00`）。依据：[T-1 §4](T-1-规则表与数值定稿.md#4-事件协议回放字段总表)。
- 不兼容变更：读取器按精确长度校验，旧 4B 载荷、旧事件流、旧回放一律拒绝；`rulesVersion` 1→2 的拒绝播放在 M1 落地。依据：[T-1 §4](T-1-规则表与数值定稿.md#4-事件协议回放字段总表)、[replay-format §5](../../specs/replay-format.md#5-播放规则)。

## 3. 跟庄

- 触发：赢家 ≠ 庄家且 `followingBanker > 0`，抢杠胡同样算；庄家胡、流局、变体关闭时不付。依据：[T-1 §1](T-1-规则表与数值定稿.md#1-规则总表) 跟庄行。
- 金额：赢家 +`followingBanker`、庄家 −`followingBanker`，两侧同置 `FollowingTheBanker`，每局最多一次。依据：[T-1 §2](T-1-规则表与数值定稿.md#2-支付与叠加口径)。
- 与承包、中马独立叠加：跟庄不在承包优先级比较集内，庄家可同时是马 payer 或承包者。依据：[T-3 §3](T-3-抢杠与承包.md#3-承包)。
- 支付矩阵见 [T-1 §2](T-1-规则表与数值定稿.md#2-支付与叠加口径)。

## 4. 结算顺序与事件

本节是 M0.3 结算顺序的唯一家，T-3、T-4 链接此处且不自立顺序。

自摸、抢杠、承包统一五步，同 tick 内不可交换：

1. 记胡牌金额：抢杠 → 抢杠记账；自摸且承包 → 对应承包记账；否则 `ApplySelfDrawn` 常规三家付。
2. 跟庄：赢家 ≠ 庄家且变体开启 → 庄家付 `followingBanker`。
3. 连庄奖励：赢家 = 庄家且 `bonus > 0` → 三家各付 `bonus`。
4. 中马：变体开启即从 `GameState.Wall` 头端取一张并追加到 `GameState.Revealed`（墙数 −1），`horseSeat = tile.Id % 4`，并产 `HorseRevealed`；命中赢家才三家各付 `horseBonus`；墙空则整步跳过。
5. 收尾：取样 `RoundDelta`、`RoundActionType` → `Release` → 写回 `PlayerState.Score` 镜像 → 构造 `RoundResult` → 产 `HorseRevealed`（若有）→ 产 `RoundEnded`。

```csharp

// 流局：RollbackRound + Release（净 0），庄家与 dealerStreak 均不变。
private void CompleteDrawRound(byte roundNo, byte bankerSeat) { }
```

- 流局走 `CompleteDrawRound`：不记连庄、跟庄、中马，产 `RoundEnded(-1, 全 0, None)`。依据：[scoring §4](../../subsystems/scoring.md)。
- 局末转移两条路径写死：`CompleteSelfDrawnWin` 返回值即下局 `bankerSeat`（庄胡 streak +1，非庄胡 = 1）；`CompleteDrawRound` 两者都不改；连庄判定取 `WinnerSeat = BankerSeat`（`RoundResult.BankerSeat` 为轮换前庄家），流局赢家为 `RoundResult.NoWinnerSeat`。
- 事件顺序：`RoundStarted` 每局开场一次并带本局 `dealerStreak`，`HorseRevealed` 紧邻 `RoundEnded` 之前、同 tick，其后同 tick 可产 `GameEnded`。依据：[T-1 §4](T-1-规则表与数值定稿.md#4-事件协议回放字段总表)。
- 结算文案落点 = 客户端 `LocalGame.ActionName`，按位追加「连庄」「跟庄」；`GetDescription` 全仓零命中，不新增 Core 侧类型。依据：符号 `LocalGame.ActionName`。
