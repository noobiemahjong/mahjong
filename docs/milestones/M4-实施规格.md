# M4 实施规格

状态：未开工
对应 master：[M4 计划](M4-打磨.md)

## T-1 Bot 基线测量与优化

- 先测：表冷加载、常驻内存、单次决策耗时、4 Bot 8 局耗时（M0.2 基线）。
- 表格式优化：若内存/加载不达标，转排序数组/分块/压缩（改格式需 Note + 金标回放）。
- 策略：在合法策略上增加牌效/听牌权重；仍走同一 `IBotPolicy` 与流事件。
- 验收：基线对比表；同 seed 确定性不变；8 局自动完成。

## T-2 回放浏览器

- 列表：本地/服务器最近 30 局；下载（M3 token）；删除本地缓存。
- 播放：复用 M1 播放器；选轮/倍速/拖动；显示对局信息（时间/玩家/结果）。
- 测试：下载→播放→删除；版本不匹配置灰。

## T-3 性能与内存

- 服务器：50 房间 × 4 Bot 压测；tick p99、CPU、内存；每房间开销。
- 客户端：AOT 启动、对局峰值内存、连续 3 局无增长。
- 工具：`benchmarks/` 脚本 + 结果表；不达标先定位再优化。
- 验收：数字写进 M4 结果；低于 M0.2/M3 基线不通过。

## T-4 音频基础美术与收口

- 音频：按钮/发牌/出牌/碰杠胡/结算音效；音量设置（沿用旧素材，授权确认）。
- 美术：牌面/桌面基础皮肤；不引入动画系统重构。
- 设置：音效/音乐开关、语言占位（中文）。
- 文档：architecture 更新；cookbook/settings；M4 结果/缺口。
