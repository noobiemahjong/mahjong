## T-1 SessionStream 正式化

`Mahjong.Core.Stream`：

````csharp
public sealed record StreamFrame(long Seq, long Tick, StreamEventKind Kind, ReadOnlyMemory<byte> Payload);
public enum StreamEventKind : byte { Batch=1, RoundStarted, TurnStarted, Drew, Discarded, Meld, RequestOpened, RequestClosed, RoundEnded, GameEnded, SeatStateChanged }
public interface ISessionStream { IReadOnlyList<StreamFrame> Drain(); }
public interface ISessionRecorder { void Write(StreamFrame frame); void Flush(); }
````

- 每帧 payload 用**手写二进制**编码（同 T-5 协议风格）；事件字段与 M0.2 SessionEvent 一一对应。
- 可见性：座位流按座位过滤手牌身份；全景流不过滤。**过滤在产出侧**。
- seq 单调、tick 单调；Drain 后不再重复；同一 tick 事件可合并为 Batch。
- 本地单机也走同一 Stream（M0.2 的 SessionEvent 映射过来），避免两套。

## T-2 回放文件

- 严格实现 [replay-format](../specs/replay-format.md)。
- Writer：`ReplayWriter.Create(path, header)` + `Append(frame)` + `Close(index)`；reader 反向。
- 校验：magic/version/长度/尾哈希；损坏抛可读错误；版本/内容哈希不匹配拒绝。
- 文件写入 `replays/`；文件名规则见格式文档。

## T-3 回放播放器

- Godot 场景 `ReplayPlayer.tscn`：复用 M0.2 的 Table 视图；数据源从 `GameSession` 换成 `ReplaySource`。
- `ReplaySource`：按 seq 提供帧；`FastForwardTo(tick)` 静默应用到目标 tick。
- UI：8 轮列表（轮号/赢家/分数）、播放/暂停、0.5–8x、±5s、±1 轮、进度条。
- 拖动/选轮 = 从 0 静默重放到目标 tick（不渲染），再继续；8 局 <200ms。
- 全景：强制所有手牌可见，标注“全景回放”；不显示操作按钮。
