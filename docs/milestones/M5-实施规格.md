# M5 实施规格

状态：见任务表
对应 master：[M5 计划](M5-移动端.md)

## T-0 Android 链路探针（先于 T-1）

目标：证明 **本机** Android 工具链 + Godot 4.7.2 + net10 + AOT 可用，或明确降级。

> Android AOT 分支在 Godot 4.7.2 源码层已确认存在，但没有本机 Android 实测（当时无 SDK/NDK）；本机现在也没有 NDK。所以 T-0 只补本机实测，不重复源码层结论。

- 工具链：JDK 17、Android SDK 35、**NDK 27（本机未装，先装）**、adb、Godot export templates 4.7.2 mono；路径写入 `docs/handbook.md`。
- 命令：Godot `--install-android-build-template`（如缺）、`--export-debug "Android"`（T-0 自带最小预设）、`adb install`、`adb logcat`。
- 断言：APK 安装并启动到 Main，logcat 打印 `M5 PROBE OK`；**不断言 AOT/CONTENT**（这些归 T-1）。
- T-0 只回答“工具链 + Godot Android 导出可用吗”；AOT 是否可用在 T-1 release 导出后回答。
- Go/No-Go 写入 M5 结果；No-Go 则 T-1 停。

## T-1 Android 构建链路

- 包名 `com.noobiemahjong.mahjong`；versionCode 1、versionName 1.0；minSdk 26；targetSdk 35；ABI arm64-v8a。
- SDK 路径：`ANDROID_HOME`/`ANDROID_SDK_ROOT`；脚本参数 `-ApkPath -Keystore -StorePass -KeyAlias -KeyPass`。
- 预设：Android，export path `build/android/Mahjong.apk`；`export_filter="all_resources"`。
- 签名：`MAHJONG_KEYSTORE` / `MAHJONG_KEYSTORE_PASSWORD` / `MAHJONG_KEY_ALIAS` / `MAHJONG_KEY_PASSWORD`；未设则 debug 签名，验收只用于调试包。
- 内容打包：导出前运行 `tools/sync-content.ps1` 把仓根 `content/`（含 M4 新增 `audio/art`）同步到 `src/Mahjong.Client/content/`；`export_filter=all_resources` 将其打进 pck。
- 启动时 Client 用 Godot FileAccess 解到 `user://content/`，再把目录传给 `ContentCatalog`；`ContentPaths` 增加“由 Client 显式传目录”入口（不把 Godot 依赖带进 Core）。
- T-1 验收：APK 正常启动并 logcat 打印 `CONTENT OK <hash>`；release 导出产物无 `coreclr`/JIT 回退标记。
- 脚本 `tools/build-android/build-android.ps1`：输入 APK 路径/keystore，输出 apk，退出码 0/1。

## T-2 触摸与布局

- `InputRouter` 接口放 `Mahjong.Client/Input/`：`IPointerSource`（Down/Move/Up）、`ClickRouter`；桌面鼠标与触摸各一实现；hover/右键只能是增强，不能是唯一入口。
- 布局：1280×720 基准；支持 16:9（1280×720）与 20:9（2400×1080）；`display/window/handheld/orientation` 用 Godot 4.7 的 Landscape 预设；安全区用 `DisplayServer.get_display_safe_area()` 包一层 MarginContainer；最小字号 24px。
- 导航：`Main.tscn`（M4 T-4）→ 单机/回放/设置；Android 返回键回上级/退出确认。
- 验收：两种分辨率截图；刘海不遮挡；点击/长按阈值 500ms。

## T-3 性能与内存

- 目标机型：中端 Android（API 26+，4GB RAM）；冷启动到 Main <5s；对局 60fps p95；峰值内存 <512MB；连续 3 局无增长；无 ANR。
- 测量：`adb shell am start -W` 冷启动；Godot profiler；`dumpsys meminfo`；fps 采样 60s。
- 验收：数字写 M5 结果；不达标先降特效再复测。

## T-4 真机验收与收口

- 清单：安装→Main→单机 8 局→结算→回放→设置→返回→退出；截图/录屏/logcat 存 `build/android/evidence/`。
- 文档：architecture 移动端差异、cookbook/android.md、M5 结果/缺口；doc-gate/CI 绿。
