# M4 实施规格

状态：见任务表
对应 master：[M4 计划](M4-打磨.md)

## T-1 Bot 基线测量与优化

先测后改，四项基线。注意：M0.1 T-3 已把 6 张表（含 ai）作为内容加载；M0.2 Bot 只要求合法、不**使用** ai 表。本任务首次把 ai 表接入决策并测决策开销。

| 指标 | 方法 | 目标 |
|---|---|---|
| ai 表冷加载 | 新进程 Stopwatch 3 次中位数 | ≤300ms（开发机） |
| 常驻内存 | 加载后 GC + Process.WorkingSet64 | ≤250MB |
| 单次决策 | 10k 次采样 p99 | ≤1ms |
| 4 Bot 8 局 | 全自动 | ≤5s |

- **M4 不改 `content/tables/*.bytes`**（红线：表不可手改）；只优化内存布局/索引/策略。若必须改表格式，另开 Note、升 rulesVersion、作废旧金标/回放并重录，不属本任务默认范围。
- 先记录基线再优化；T-1 必须先于 T-2。
- 策略：在合法策略上加牌效/听牌权重；仍走 `IBotPolicy`；同 seed 确定性不变。
- 验收：基线表 + 优化后对比；8 局自动完成。

## T-2 回放浏览器

- 列表：M3 `GET /replays`（最近 30 局）；本地缓存 `user://replays/`；删除本地缓存。
- 下载：`POST /replays/{id}/token` → `GET /replays/{id}?token=`；Range 续传。
- 播放：复用 M1 `ReplayPlayer.tscn`；显示时间/玩家/结果（来自 Index scoreDelta）；8 局列表显示庄家。
- 版本/内容不匹配：条目置灰，可看元数据，不可播放；提示原因。
- 不做分享链接（D14）；不做上传。
- 验收：下载→播放→删除；版本不匹配置灰；断点续传。

## T-3 性能与内存

- 服务器：`Mahjong.Server --loadtest 50 --bots 4`（仅该开关绕过 D13 空房销毁）；50 房间 × 4 Bot；tick p99、CPU、每房内存。
- 目标：tick p99 ≤5ms（口径：单房间每 tick `Step` 耗时 p99）；每房常驻 ≤8MB；50 房总内存 ≤1.5GB（开发机基线，记录 CPU/内存）。
- 若 M3 未记录服务器基线，本任务先测当前值作为基线；结果写 M3/M4 结果。
- 客户端：AOT 启动 ≤3s；对局峰值 ≤512MB；连续 3 局无持续增长。
- 工具：`tools/benchmarks/run.ps1` + 结果写 `docs/reference/m4-bench.md`。
- 验收：数字达标/记录；低于 M0.2/M3 基线不通过。

## T-4 音频、设置与导航

- 音频落点 `content/audio/{bgm,sfx,voice}/`；沿用旧项目 74 条 Mandarin 语音（34 牌名 + 3 技能，男/女各一套）与 9 条音乐/音效（3 BGM + 6 SFX）；清单 `content/audio/manifest.json` 记录来源与用途。
- 播放：`AudioStreamPlayer` + Master/SFX/Music 总线；牌名语音按 `content/audio/manifest.json` 的 `gender` 配置选包，无配置用 Female 包；弃牌/摸牌/技能/按钮/结算分别接线。
- 设置：`user://settings.json`：`soundOn, musicOn, masterVolume, sfxVolume`；启动加载、修改即存；缺文件用默认值。
- 导航：新增 `Main.tscn`（单机/联机/回放/设置/退出），`run/main_scene` 改为 `Main.tscn`；联机入口接 M3 T-6 `RoomJoin.tscn`；Android 返回键回上级（M5）。
- 验收：74 条语音与 9 条音乐/音效逐项可触发；BGM 按界面切换；音量/开关重启后保持；导航全路径可达、无死链；文档 `cookbook/settings.md`（音量/开关/存储路径）。

## T-5 旧素材落地与 UI 成品化

### 输入与落点

- 旧项目素材只读；复制到 `content/art/`、`content/fonts/`，音频归 T-4。
- `content/art/manifest.json` 每项记录：旧路径、目标路径、用途（界面/元素）、尺寸/九宫格；缺项即不通过。
- 资产权利：已确认旧项目素材可复用（自有版权/已授权）；入库时在 manifest 记录来源，不再设版权阻塞。
- 同步：新建 `tools/sync-content.ps1` 把 `content/` 复制到 `src/Mahjong.Client/content/`；导出前执行（M5 T-1 同机制）。
- 内容边界：美术/字体/音频是客户端资源，**不进 `content/manifest.json` 的 contentHash 清单**（服务端不加载）；分别用 `content/art/manifest.json`、`content/audio/manifest.json`、`content/fonts/manifest.json` 记录来源与用途。若以后要求视觉一致性参与握手，升 rulesVersion 并另开 Note。
- 服务端镜像：M3 Dockerfile 的 `COPY content/` 改为只复制 `manifest.json`、4 个 JSON 与 `tables/`；art/audio/fonts 不进服务端镜像。
- Unity Prefab（139 个）/Scene（5 个）不直接迁移；牌桌/面板/指示器按 Godot 场景重做，只复用贴图、字体与音频。

1. 全部 v1 可达界面无占位：无 `Panel`+`Label` 牌面、无默认字体、无默认 `Button`、无缺图洋红。
2. 34 种牌在四家相对座位的手牌/弃牌/副露/亮牌/胡牌状态显示正确；鬼牌与牌背正确。

6. UI 样式集中在 `Theme`；场景不写死字体/颜色/纹理路径（牌面/头像引用除外）。
7. AOT 导出包包含 `content/art`、`content/fonts`；导出 exe 截图与编辑器一致。
8. `docs/reference/art-mapping.md` 记录每屏素材映射与验收截图。
