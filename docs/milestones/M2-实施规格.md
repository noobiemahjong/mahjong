# M2 实施规格

状态：见任务表
对应 master：[M2 计划](M2-局域网.md)

## T-1 发现

- `LanDiscoveryResponder`：绑定配置的发现端口（默认 47777）；持有 `IRoomAdvertisement`：
  `RoomName, HostName, Players, MaxPlayers, GamePort, ProtocolVersion, RulesVersion, ContentHash, TickRate, HasPassword, IsPlaying`。
  **不依赖 T-2**：游戏端口来自配置，状态由 T-2 后续更新。
- `LanDiscoveryClient`：枚举网卡 → 定向广播 + 255.255.255.255；1s 超时；按 nonce 去重。
- UI：房间列表（名称/人数/版本/状态）+ 手动 IP；选中后连游戏端口。
- 约束：一个 responder 只服务一个房间；同机多房间 = 多进程 + 不同发现端口。
- 测试：同机回环；版本不匹配置灰；无 responder 超时不崩；两进程不同端口各发现一房。

## T-2 传输与房主内嵌会话

- `TcpSessionHost` 放 **Mahjong.Session**（Client 引用 Session；见 Note `2026-10-28-client-session-dependency`）。
- `TcpListener`/`Socket` + `System.IO.Pipelines`；每连接一个读任务 + 写队列；帧解析按 [protocol](../specs/protocol.md)。
- 房主进程内起权威 `GameSession`；4 玩家 + 最多 8 观战；命令入队，tick 驱动；事件按座位/观战/全景过滤后广播。
- 握手：Hello 带 roomCode/password/role；Welcome 返回 playerToken；三元组不匹配 Reject（原因码见 protocol §2）。
- 网络线程只做 I/O；会话逻辑单线程；队列交接，无锁共享状态。
- 测试：本机 4 客户端完成一局；坏帧/超大帧断开；密码错/版本错拒绝。

## T-3 重连与托管

- 断线：按 protocol §3 心跳规则（Ping 5s / 15s 无帧断开）；座位进入 **Grace(30s=300 tick)**。
- 到期 Bot 接管（M0.2 T-4）；玩家回来立即交还，deadline 重置为完整时长。
- 重连：`Resume(token, lastAckSeq)` → 从 seq=1 用 M1 `ISessionStream.GetFramesFrom(1)` 全量重放本人流 → 补 `RequestOpened` → 恢复交互。
- 幂等：`(seat, requestId)` 去重；旧连接踢掉；token 错拒绝。
- 测试：30s 内重连、60s 后重连、重复命令、对局中重连。

## T-4 观战

- 无座位连接；`SpectatorSlot` 上限 8；流可见性 = `VisibilityPolicy.Spectator`（无手牌玩家）。
- 中途加入：先 `GetFramesFrom(1)` 重放历史，再实时；只读，不接受 Command。
- 私有房可选 **全知观战**（默认关，房主开启）：用 Panorama 流，UI 标注。
- 不影响计时/结算；房间设置可关。
- 测试：中途加入只看到公开信息；手牌不可见；观战断开不影响对局。

## T-5 收口

- 启动参数：`--host --room <code> --discovery-port <p> --game-port <p>`；`--join <ip> --game-port <p>`；`--spectate <ip> --game-port <p>`。
- 日志标记：`LAN HOST READY port=<p>`、`LAN JOINED seat=<n>`、`LAN GRACE seat=<n>`、`LAN BOT TAKEOVER seat=<n>`。
- 两房间并行：两个进程 + 不同发现/游戏端口；4 客户端；重连（断网 30s/60s）；观战；版本拒绝。
- 文档：architecture 更新、subsystems/network.md、cookbook/lan.md、M2 结果。
- LAN 回放下载归属 M4 T-2（房主 HTTP）；M3 只做 VPS 形态。
