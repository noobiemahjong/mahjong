## 4. 验收

- 使用 `--record` 跑 8 局单机对局生成 `.mjr`；播放能看到全部手牌；选局/快进/快退/拖动可用。
- Trailer 的 `finalStateHash` 与回放终态一致；同文件两次播放一致；拖动到第 8 局 <200ms（开发机）。
- 根 `.gitignore` 已忽略 `replays/`、`build/`；录制失败不阻断对局。
- 版本/内容哈希不匹配拒绝播放；损坏文件报错可读。
- 文档：architecture 更新、subsystems/replay.md、cookbook/replay.md、M1 结果。

## 5. 完成定义

1. 生成/读取/播放 `.mjr` 全链路通过。
2. 8 局回放、选局、倍速、拖动验收通过。
3. 金标测试与性能基线记录。
4. 文档齐全、doc-gate/CI 绿；范围守门（无网络/观战）。
