# T-5 本地会话（实施规格）

状态：见任务表
依赖：T-1b、T-3、T-4
对应 master：[M0.2](../M0.2-单机可玩闭环.md)
验收：人类脚本/4 Bot 走完 8 局；事件流可消费；两会话隔离；无网络代码。

## 1. API

命名空间 `Mahjong.Session`；`GameSession` 是 `sealed partial class`；请求/命令/位集复用 `Mahjong.Core.Flow`（D1）。

```csharp
// 签名摘要（省略实现体与 XML doc）。
public enum SessionEventKind : byte { RoundStarted = 1, TurnStarted, Deal, HandSync, Drew, Discarded, Meld, RequestOpened, RequestClosed, RoundEnded, GameEnded, SeatStateChanged }
public readonly record struct SessionEvent(long Seq, long Tick, SessionEventKind Kind, ReadOnlyMemory<byte> Payload);
public sealed record SessionConfig(byte? HumanSeat, byte BotCount, int TickRate = 10, int TurnTimeoutTicks = 600, int ResponseTimeoutTicks = 150);
public readonly record struct SubmitResult(bool Accepted, string? Reason, long RequestId);

public sealed class GameSession
{
    public GameSession(SessionConfig config, ContentCatalog content, IWinChecker wins, IRandomSource rng);
    public GameState State { get; }  public long Tick { get; }  public bool IsStarted { get; }  public bool IsGameOver { get; }
    public IReadOnlyList<PendingRequest> ActiveRequests { get; }   // requestId 升序；无请求为空只读列表
    public void Start();  public void Step(long tick);  public SubmitResult Submit(GameCommand command);
    public IReadOnlyList<SessionEvent> DrainEvents(byte viewerSeat);   // 0–3 或 255；破坏性
}
```

- 构造只收 `(config, content, wins, rng)`，不含 `TableCatalog`（D2）；`SessionConfig` 不含 `ContentDirectory`（D3）；鬼牌只取 `content.Joker` 的 `FixedType`，无鬼用 `default(TileType)`；合法组合只有 `(null, 4)` 与 `(0–3, 3)`，`TickRate`/两个超时均至少 1，四参 null 抛 `ArgumentNullException`、配置非法抛 `ArgumentException`/`ArgumentOutOfRangeException`（`ParamName` 为 `config`）。
- `Start` 二次调用抛 `InvalidOperationException`；`Step` 未 Start 抛、`tick` 非严格递增抛；`GameOver` 后 `Step` 只更新 `Tick`、`Submit` 返回 false、不产事件；`Submit` 非法一律 `false` + 非空 `Reason`，成功只记录应答。
- `DrainEvents` viewer 非法抛 `ArgumentOutOfRangeException`，未 Start 或已排空返回空列表；`SessionEventPayloadReader` 是 payload 唯一公开读取入口，`Kind` 不匹配抛 `ArgumentException`，截断/计数矛盾/非法 UTF-8/名次越界抛 `InvalidDataException`。

### 1.1 事件 payload（权威布局）

整型一律小端、字段按序紧排、无对齐填充。

| Kind | 字节 |
|---|---|
| RoundStarted | roundNo u8、bankerSeat u8、wallCount u16 |
| TurnStarted | seat u8、deadlineTick i64 |
| Deal | seat u8、count u8、tileIds u16[count]；非本人/255 只写 seat,count |
| HandSync | 同 Deal；M0.2 不产出 |
| Drew | seat u8、tileId i32（非本人且非 255 为 -1）、wallCount u16 |
| Discarded | seat u8、slot u16（弃牌区槽位，追加后下标）、tileId u16 |
| Meld | seat u8、kind u8(MeldKind)、count u8、tileIds u16[count]、targetSeat u8（255=无） |
| RequestOpened | requestId i64、seat u8、kind u8(RequestKind)、allowed u16、deadlineTick i64 |
| RequestClosed | requestId i64、outcome u8、answerLen u16、answer bytes；Answered = verb u8 + slot u16 + cardId u16（5B），其余 0B |
| RoundEnded | winnerSeat i8（-1=流局）、scoreDelta i32[4]、actionType u16 |
| GameEnded | totalScores i32[4]、ranking u8[4]、replayIdLen u8 + replayId UTF8（M0.2 为空） |
| SeatStateChanged | seat u8、state u8（0 Online / 1 Grace / 2 Bot / 3 Offline） |

可见性：viewer = 该事件座位或 255 才给 tileId，其他座位 Deal/HandSync 只给 count、Drew 给 -1；其余事件全量可见（暗杠不隐藏）。`Seq` 从 1 单调、Drain 后不重复；`Tick` 是产出事件的逻辑 tick；payload 由 `SessionEventBuffer` 内部写入，读取器返回数组是副本。

### 1.2 裁定落地（D1–D13）

- D1–D3：复用 `Core.Flow` 命令/请求/位集类型，不重复定义；构造不含 `TableCatalog`；`SessionConfig` 不含 `ContentDirectory`、会话不读文件系统。
- D4–D6：自己回合 `Discard` 请求 `allowed` 可含 `Kong`（杠合法时）、不新增 `RequestKind`；回合之间无 Ready 门（`RoundEnded` 后同 tick 开下一局）；`HandSync` 不产出。
- D7–D9：单根动作协程 + `WaitUntil`、无子动作/abort；`DrainEvents` 破坏性单消费者、无 per-viewer 游标；超时托管（自动出第一张合法牌、Win 按 Pass、窗口到 deadline 关闭）。
- D10–D13：Core 改三处（`RoundResult` 构造器 public、`RoundRanking.Rank` 且 `RoundController.Rank` 委托、新增 `ApplySevenPairsSelfDrawn`）；additive API（`IsStarted`/`IsGameOver`/`ActiveRequests`、读取器与 payload structs）；Bot 延迟 `max(1, ceil(TickRate × 300 / 1000))` tick；`arrivalSeq` = 调用时 `Tick`。

## 2. 回合流程

单根动作协程 `RunGameLoop` 是 8 局线性状态机，每个 tick 由 `Step` 推进到下一个等待点。

```text
for roundNo in 1..8:
  banker = roundNo==1 ? rng.NextUInt()%4 : 上局轮换值
  Deal(rng,banker); emit RoundStarted(roundNo,banker,84) + Deal×4
  emit TurnStarted(banker); DrawFromWall(banker); emit Drew(83)
  loop:
    if hasDrawn: 可自摸/七对则开 Win 请求(Win|Pass)，应答 Win 则结算本局
    allowed = Discard | (暗杠/补杠合法 ? Kong : 0)；开 Discard 请求
    应答 Discard/超时自动出牌 → Discard + emit Discarded；应答 Kong → Commit + Meld + 杠分 + 补牌 Drew
    无摸牌时开 Discard 请求(Discard) → 强制出牌
    其他座位碰/明杠合法 → OpenGroup + 等待关闭；胜者 Commit + emit Meld（明杠杠分+补牌）
    无人响应 → 下家；摸牌前墙空 → 流局结算；否则 TurnStarted + 摸牌 + Drew
8 局后 emit GameEnded；IsGameOver = true
```

- 事件顺序与边界：`Deal` 后 `Wall` 84、四家 13、`CurrentSeat` = 庄家，庄家摸第 14 张（`Wall` 83）；`TurnStarted` 只在从墙头摸牌开始新回合时产出（碰/杠后强制出牌与补牌不产），流局判据是下家摸牌前 `Wall.Count == 0`；同一 tick 的 `RequestClosed` 先于协程恢复后的 `Discarded`/`Meld`/`Drew`。
- 杠扩展（D4）：自己回合 `Discard` 请求可含 `Kong`；`Commit` 后 `Melds.Count` 增加即暗杠、否则原碰原地升级为补杠，`Meld.targetSeat` 碰/明杠为被取弃牌座位、暗杠/补杠为 255，补牌从手牌末张读取并产 `Drew`。
- 结算与托管：取样 delta/actionType → `Release` → 写回镜像 → 构造 `RoundResult` → 产 `RoundEnded`；七对走 `ApplySevenPairsSelfDrawn`，普通自摸 `kongUpFlower` 只看赢家本回合最近摸牌是否杠后补牌，流局 `RollbackRound` + `Release`（净 0）；出牌/Win 超时自动出第一张合法牌/按 Pass，响应窗口未应答者 TimedOut，Bot 按 D12 延迟走相同 `Submit` 路径。

## 3. 本地组装

- `LocalSessionFactory` 是组装根：`Create(SessionConfig, ContentCatalog, TableCatalog, ulong seed)`、`CreateSinglePlayer(..., int tickRate = 10)`、`CreateFourBots(..., int tickRate = 10)`。
- `CreateSinglePlayer` = `SessionConfig(0, 3, tickRate)`（0 号真人、1–3 Bot）；`CreateFourBots` = `SessionConfig(null, 4, tickRate)`；两者都用 `new WinChecker(tables)` 与 `new Pcg32(seed)` 构造会话，**不调用 `Start`**。
- `TableCatalog` 只在组装根使用，会话只接收 `ContentCatalog`/`IWinChecker`/`IRandomSource`；宿主按固定 tick 调 `Step` 并消费 `DrainEvents`，单线程、无锁、无静态可变状态。
