# M5 实施规格

状态：未开工
对应 master：[M5 计划](M5-移动端.md)

## T-1 Android 构建链路

- Godot 4.7.2 mono 导出 Android；.NET 10 + AOT 链路按 M0.1 的 AOT 配方调整（Android 需 NDK/签名）。
- 构建脚本：`tools/build-android.ps1`；产物 `build/android/Mahjong.apk`；版本号/包名固定。
- 先决：JDK/Android SDK/NDK 路径写入文档；证书/签名配置不入库（用户提供）。
- 验收：模拟器/真机安装启动；logcat 无致命错误。

## T-2 触摸与布局

- 输入抽象已有（M0.2），补触摸：点选/再点提交；长按提示；无 hover 依赖。
- 布局：Control 锚点/容器；16:9–20:9 安全区；牌桌缩放；字体可读。
- 测试：两种分辨率截图；横屏；安全区不被刘海遮挡。

## T-3 性能与内存

- 目标：中端 Android 60fps；启动 <5s；对局峰值内存 < 预算（M5 启动时定）。
- 工具：Godot profiler + 自建 alloc probe；关闭/降低特效分级。
- 验收：数字记录；连续 3 局无增长/ANR。

## T-4 真机验收与收口

- 真机清单：安装→启动→单机 8 局→结算→回放→设置→退出。
- 截图/录屏/日志作为证据；问题记 pitfalls/bugs。
- 文档：architecture 移动端差异；cookbook/android；M5 结果与缺口。
