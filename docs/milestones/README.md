## 任务文档形态

- 阶段 master：`M<N>-<名称>.md`，含范围、任务分解表、验收口径、结果。
- 任务：`M<N>/T-<n>-<短名>.md`，含依据 / 判据 / 依赖 / 实施记录。
- 状态列取值：`未开工` / `进行中` / `已完成` / `阻塞`（阻塞必须写原因与解除条件）。
- 进入下一阶段前，本阶段所有任务必须有结果；未完成任务要么降级为「后续承接项」并写明落点，要么不开下一阶段。
