# M5 实施规格

状态：见任务表
对应 master：[M5 计划](M5-移动端.md)

## T-0 Android 链路探针（先于 T-1）

目标：证明 Godot 4.7.2 + net10 + AOT 在 Android 可用，或明确降级。

- 工具链：JDK 17、Android SDK 35、NDK 27、adb、Godot export templates 4.7.2 mono；路径写入 `docs/handbook.md`。
- 命令：Godot `--install-android-build-template`（如缺）、`--export-debug "Android"`、`adb install`、`adb logcat`。
- 断言：APK 启动打印 `CONTENT OK <hash>`；无 `coreclr`/JIT 回退标记；若 AOT 不可用 → 记 Note，M5 降级为 Mono 并明确不满足 v1 性能目标。
- Go/No-Go 写入 M5 结果；No-Go 则 T-1 停。

## T-1 Android 构建链路

- 包名 `com.noobiemahjong.mahjong`；versionCode 1；minSdk 26；targetSdk 35；ABI arm64-v8a。
- 预设：Android，export path `build/android/Mahjong.apk`；`export_filter="all_resources"`。
- 签名：`MAHJONG_KEYSTORE` / `MAHJONG_KEYSTORE_PASSWORD` / `MAHJONG_KEY_ALIAS` / `MAHJONG_KEY_PASSWORD`；未设则 debug 签名，验收只用于调试包。
- 内容打包：`content/` 作为 Godot 资源进 pck；启动时 Client 用 Godot FileAccess 解到 `user://content/`，再把目录传给 `ContentCatalog`；`ContentPaths` 增加“由 Client 显式传目录”入口（不把 Godot 依赖带进 Core）。T-3 M0.1 同批加该分支说明。
- 脚本 `tools/build-android/build-android.ps1`：输入 APK 路径/keystore，输出 apk，退出码 0/1。

## T-2 触摸与布局

- `InputRouter` 接口放 `Mahjong.Client/Input/`：`IPointerSource`（Down/Move/Up）、`ClickRouter`；桌面鼠标与触摸各一实现；hover/右键只能是增强，不能是唯一入口。
- 布局：1280×720 基准；支持 16:9–20:9；安全区用 `DisplayServer.get_display_safe_area()`；横屏；字号可读。
- 导航：`Main.tscn`（M4 T-4）→ 单机/回放/设置；Android 返回键回上级/退出确认。
- 验收：两种分辨率截图；刘海不遮挡；点击/长按阈值 500ms。

## T-3 性能与内存

- 目标机型：中端 Android（API 26+，4GB RAM）；冷启动到 Main <5s；对局 60fps p95；峰值内存 <512MB；连续 3 局无增长；无 ANR。
- 测量：`adb shell am start -W` 冷启动；Godot profiler；`dumpsys meminfo`；fps 采样 60s。
- 验收：数字写 M5 结果；不达标先降特效再复测。

## T-4 真机验收与收口

- 清单：安装→Main→单机 8 局→结算→回放→设置→返回→退出；截图/录屏/logcat 存 `build/android/evidence/`。
- 文档：architecture 移动端差异、cookbook/android.md、M5 结果/缺口；doc-gate/CI 绿。
