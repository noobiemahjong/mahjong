## 1. 计分

落点 `Mahjong.Core.Rules`；类型与语义契约见 [scoring.md §1–§3](../../subsystems/scoring.md)，本节只留任务口径与验收锚点。

````csharp
// 示意/伪代码：签名摘要，省略实现体与 XML doc，不可直接编译。
[Flags] public enum ScoreActionType : ushort
{
    None = 0, SelfDrawn = 1, SevenPairs = 2, ConcealedKong = 4, ExposedKong = 8,
    KongSupplement = 16, KongUpFlower = 32, NoJoker = 64,
}
public sealed class ScoreManager
{
    public void Apply(byte seat, short delta, ScoreActionType type);
    public void ApplySelfDrawn(byte winnerSeat, bool hasJoker, bool sevenPairs, bool kongUpFlower);
    public void ApplyKong(byte seat, MeldKind kind, byte sourceSeat = Meld.NoTargetSeat);
    public void RollbackRound();
    public void Release();
    public IReadOnlyList<short> RoundDelta { get; }
    public IReadOnlyList<short> TotalScores { get; }
    public ScoreActionType RoundActionType { get; }
}
````

- 验收锚点：无鬼自摸 +12/-4×3、有鬼 +6/-2×3、七对再 ×2、杠上开花再 ×2；明杠 +3/-3、暗杠 +6/-2×3、补杠 +3/-1×3；单次自摸/杠四座 delta 之和为 0。
- 账本与校验：两段式暂存/发布、流局先 `RollbackRound` 再 `Release` 净 0、金额上界（单次自摸 ≤+24、单次杠 ≤+6，不做溢出保护）、只读快照、标记位与三种非法组合、异常类型（`ArgumentOutOfRangeException`/`ArgumentException`/`InvalidOperationException`）均以 [scoring.md §1–§3](../../subsystems/scoring.md) 为准。

## 2. 轮次

落点 `Mahjong.Core.Rules`；驱动契约与异常边界见 [scoring.md §4–§7](../../subsystems/scoring.md)。

````csharp
// 示意/伪代码：签名摘要，省略实现体与 XML doc，不可直接编译。
public enum RoundCommandKind : byte { Discard = 1, Win = 2 }
public readonly record struct RoundCommand(byte Seat, RoundCommandKind Kind, int Slot = 0)
{
    public static RoundCommand Discard(byte seat, int slot);
    public static RoundCommand Win(byte seat);
}
public sealed class RoundController
{
    public const byte TotalRounds = 8;
    public RoundController(IWinChecker wins, IRandomSource rng, TileType joker = default);
    public byte RoundNo { get; }
    public byte BankerSeat { get; }
    public bool IsGameOver { get; }
    public ScoreManager Scores { get; }
    public RoundResult RunRound(GameState state, IReadOnlyList<RoundCommand> commands);
    public IReadOnlyList<byte> Rank();
}
public sealed class RoundResult
{
    public const byte NoWinnerSeat = 255;
    public byte RoundNo { get; }
    public byte BankerSeat { get; }
    public byte WinnerSeat { get; }
    public bool IsDraw { get; }
    public ScoreActionType ActionType { get; }
    public IReadOnlyList<short> ScoreDelta { get; }
    public IReadOnlyList<short> TotalScores { get; }
}
````

- 验收锚点：开局 `Wall` 84、四家 13、庄家摸后 14/83；`RoundNo` 1–8 且 9 表示 8 局已打完，第 9 次 `RunRound` 抛 `InvalidOperationException`；流局 `WinnerSeat = NoWinnerSeat`、`ActionType = None`、`ScoreDelta` 全 0；每局正常结束（含流局）后 `PlayerState.Score` 等于 `Scores.TotalScores`。
- 驱动契约：起庄只在首次 `RunRound` 消耗一次 RNG、命令逐条原子、默认出牌只服务无会话测试、流局冻结帧、庄家轮换、`Rank` 稳定序与同 seed 确定性见 [scoring.md §4–§6](../../subsystems/scoring.md)。
- 事件不进 Core：`RoundResult` 是 T-5 `RoundEnded`/`GameEnded` 的 payload 来源；杠分由 T-5 在杠 `Commit` 后调 `Scores.ApplyKong`，自摸按局内杠位传 `kongUpFlower`。

## 3. 测试

- 计分：`Apply` 累积/越界/未定义位/失败不变；自摸四档乘区与七对/杠上开花；三种杠数值与标记；三种非法组合；`RollbackRound`/`Release` 分层与幂等；只读视图；连续两局暂存归零。
- 轮次：起庄 RNG 时机、开局快照、命令逐条原子、七对优先、默认出牌跳过鬼牌、空命令流局、庄家轮换三态、8 局循环与第 9 次抛、总分镜像、`Rank` 稳定序、同 seed 确定性。
- 数值锚点按手算：单局无鬼自摸 +12/-4×3；8 局全自摸 +96/-32×3；七对无鬼 +24/-8×3。
- 用例落 `src/Mahjong.Tests/Rules/`：`ScoreManagerTests` 39 条、`RoundControllerTests` 33 条、`RoundControllerTableTests` 3 条（真查表，类级 `[Collection("table-catalog")]`），合计 75；`RoundTestSupport` 只提供共享支撑、不含用例。
