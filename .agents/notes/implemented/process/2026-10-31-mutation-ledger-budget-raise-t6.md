# Agent Note: 变异台账预算提额（T-6 中文 UI）

Status: implemented — 台账只增不减；恢复既有条目原措辞并新增 2 条后 32768B 不足，reference 上限 32KB→34KB。

## Problem

T-6 中文 UI 修订要求台账新增中文字形/字体回退条目（ML-102 删字体回退、ML-103 中文文案错配）。台账纪律是「登记行只增不减」；先前为在 32768B 内塞入 ML-102/103，我精简了 20 条既有条目（ML-001/005/014/016/021/023/026/030/042/043/044/048/068/074/076/078/091/093/098/101）的措辞，删掉「单点各已 KILLED」等证据性文字，review-docs 判为违反只增不减精神。按 476b88e 恢复这 20 条后（32613B）再加 2 条，台账为 33556B，超过 reference 单篇 32768B 上限。

## Decision

1. 按 T-4/T-5 提额先例，把单篇 reference 上限 32KB→34KB（34816B），只提台账预算，其它 reference 文档上限不变。
2. 同批改三处预算：`docs/AGENTS.md` 预算表 reference 行 32KB→34KB；`tools/doc-gate/doc-budgets.json` 与 `doc-budgets-baseline.txt` 的 `docs/reference/mutation-ledger.md` 条目 32768→34816。
3. 既有 20 条按 476b88e 原措辞恢复，不改内容；新增仅 ML-102/103。

## Alternatives considered

- **接受精简既有条目**：不升预算即可容纳；但删掉了 KILLED 等证据文字，违反「登记行只增不减」与证据可追溯，放弃。
- **把中文/字体变异登记到 T-6 规格而非台账**：台账是变异唯一登记处，分叉会形成第二登记地，放弃。
- **删除或合并旧台账条目**：直接违反只增不减，放弃。
- **本批不登记 ML-102/103**：漏登记，后续用户批次无法覆盖中文/字体变异，放弃。

## Consequences

- reference 单篇上限 34KB；台账现有 103 条，仍保留原条目全部证据文字。
- 新增条目纳入用户批次的变异执行范围；其它 reference 文档受原 32KB 约束。
- 提额理由与 T-4/T-5 先例一致：条目只增不减，预算随登记量调整。
