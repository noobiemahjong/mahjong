## 1. 目标

一句话：**把权威服务器部署到 VPS：房间码建房/加入、版本校验、赛后回放下载（保留 30 局）。**

## 2. 范围

包含：无头服务器/房间状态机、房间码、HTTP API（建房/查询/回放列表/token/下载）、版本握手、回放保留、Docker 部署、客户端接入。
不包含：官方匹配/排位、账号、TLS/反作弊、移动端。

## 4. 验收

- 3 个跨网络客户端 + 1 个 Bot 用房间码打完一场；断线重连可用。
- 版本/内容不匹配被拒绝且客户端显示原因。
- 赛后客户端列出/下载/播放回放；保留最近 30 局，第 31 局淘汰最旧。
- 空房创建后 60s 无人加入才销毁；开局后按 D13；服务器重启不影响已落盘回放。
- 文档：architecture、subsystems/server、cookbook/server、M3 结果。

## 5. 完成定义

1. VPS 部署可重复（Docker/配置/日志）。
2. 房间码 + HTTP + 版本 + 回放下载 + 客户端接入全链路通过。
3. doc-gate/CI 绿；文档与结果齐；范围守门（无匹配/账号/移动端）。
