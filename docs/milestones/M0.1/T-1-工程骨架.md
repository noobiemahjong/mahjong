## 2. 精确配置

`global.json`（T-1 创建并锁定；不是既有文件）：

````json
{ "sdk": { "version": "10.0.401", "rollForward": "latestPatch" } }
````

`Directory.Build.props`（所有工程继承；Client 可覆盖）：

````xml
<Project>
  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
    <LangVersion>latest</LangVersion>
    <Nullable>enable</Nullable>
    <ImplicitUsings>enable</ImplicitUsings>
    <TreatWarningsAsErrors>true</TreatWarningsAsErrors>
  </PropertyGroup>
</Project>
````

`.editorconfig`（必需项）：

````ini
root = true
````

`Directory.Packages.props`（CPM；只作用于 4 个 .NET 工程，Client 关闭）：

````xml
<Project>
  <PropertyGroup>
    <ManagePackageVersionsCentrally>true</ManagePackageVersionsCentrally>
  </PropertyGroup>
  <ItemGroup>
    <PackageVersion Include="Microsoft.NET.Test.Sdk" Version="17.14.1" />
    <PackageVersion Include="xunit" Version="2.9.3" />
    <PackageVersion Include="xunit.runner.visualstudio" Version="3.1.4" />
  </ItemGroup>
</Project>
````

工程：

- `Mahjong.Core`：`Microsoft.NET.Sdk`，无任何引擎/网络引用；不能出现 `Godot` 命名空间。
- `Mahjong.Session`：`Microsoft.NET.Sdk`，引用 Core。
- `Mahjong.Client`：`Godot.NET.Sdk/4.7.2`，`TargetFramework net10.0`，`PublishAot true`；引用 **Core + Session**；`TrimmerRootAssembly` 为 `Mahjong.Client`、`Mahjong.Session`、`Mahjong.Core`、`GodotSharp`；`ManagePackageVersionsCentrally false`（Godot.NET.Sdk 注入带 `Version` 的隐式 GodotSharp 引用，与 CPM 冲突）。`EnableDynamicLoading` 只在导出实测需要时加，不作为初始配置。
- `Mahjong.Server`：`Microsoft.NET.Sdk`，`OutputType Exe`，引用 Session/Core；M0.1 只要求启动后正常退出。
- `Mahjong.Tests`：`Microsoft.NET.Sdk`，xUnit；引用 Core/Session；不引用 Godot。
- 测试包：`Microsoft.NET.Test.Sdk`、`xunit`、`xunit.runner.visualstudio`，版本由 `Directory.Packages.props` 锁定（17.14.1 / 2.9.3 / 3.1.4，与本机 NuGet 缓存一致，可离线还原）；升级需同提交说明。

命名空间：`Mahjong.Core.*` / `Mahjong.Session.*` / `Mahjong.Client.*` / `Mahjong.Server.*` / `Mahjong.Tests.*`。
禁止：VContainer、UniTask、Netcode、protobuf-net、反射 DI、任何 Unity 包。

## 3. Godot 工程

`project.godot` 至少包含：

````ini
config_version=5
[application]
config/name="Mahjong"
run/main_scene="res://Startup.tscn"
[display]
window/size/viewport_width=1280
window/size/viewport_height=720
window/stretch/mode="canvas_items"
[rendering]
renderer/rendering_method="gl_compatibility"
renderer/rendering_method.mobile="gl_compatibility"
[dotnet]
project/assembly_name="Mahjong.Client"
````

- `Startup.tscn`：根 `Node` + `Startup.cs`；无游戏内容。
- `Startup.cs`：普通启动打印 `M0.1 START`；`OS.GetCmdlineArgs()` 含 `--smoke` 时打印 `M0.1 SMOKE OK`、30 帧后 `GetTree().Quit()`（导出版直接传 `Mahjong.exe --smoke`，供 T-6 AOT 冒烟）；退出码 0，不往 stderr 写内容。
- `export_presets.cfg`：Windows Desktop 预设，导出路径用仓库根绝对路径 `<repo>/build/windows/Mahjong.exe`（Godot CLI 的相对路径基准不可靠，脚本一律传绝对路径），`export_filter="all_resources"`。
- `.gitignore` 增补 `.godot/`、`*.uid`（Godot 首次导入与 .NET 构建会生成，不忽略会让工作区变脏）。

## 4. 命令与验收

````sh
dotnet build Mahjong.sln -warnaserror
dotnet test  Mahjong.sln
````

验收：

1. 构建 0 warning / 0 error；测试工程可发现并运行（0 个用例也算通过）；包版本已在 `Directory.Packages.props` 锁定，restore 可离线完成。
2. Core 程序集无 Godot 引用（编译期即可保证；再加一条反射测试扫描 referenced assemblies）。
3. Godot 打开工程无错误；`Startup.tscn` 可运行；`--smoke` 模式打印标记并退出 0。
4. Server `dotnet run` 正常退出 0。
5. Client 的 AOT 配置（PublishAot/root）存在；AOT 前置按注册表 `HKLM\SOFTWARE\Microsoft\Windows Kits\Installed Roots` 的 `KitsRoot10` 定位 SDK（本机 `E:\Windows Kits\10`）+ `vswhere -requires Microsoft.VisualStudio.Component.VC.Tools.x86.x64` 自检，结果写入实施记录；T-6 才要求可运行。
