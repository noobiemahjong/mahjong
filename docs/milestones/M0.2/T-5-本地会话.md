# T-5 本地会话（实施规格）

状态：未开工
依赖：T-3、T-4
对应 master：[M0.2](../M0.2-单机可玩闭环.md)
验收：人类脚本/4 Bot 走完 8 局；事件流可消费；两会话隔离；无网络代码。

## 1. API

`Mahjong.Session`：

````csharp
public enum SessionEventKind
{
    RoundStarted, TurnStarted, Drew, Discarded, Meld, RequestOpened,
    RequestClosed, RoundEnded, GameEnded, SeatStateChanged,
}
public sealed record SessionEvent(long Seq, long Tick, SessionEventKind Kind, object Payload);
public sealed class GameSession
{
    public GameSession(SessionConfig config, TableCatalog tables, IWinChecker wins);
    public IReadOnlyList<SessionEvent> Events { get; } // 自上次 Drain 起
    public IReadOnlyList<SessionEvent> DrainEvents();
    public void Start();
    public void Step(long tick);
    public void Submit(byte seat, Command command);
    public GameState State { get; }
    public long Tick { get; }
}
public interface IPlayerGateway { void Request(byte seat, Request request); }
````

## 2. 本地组装

- `LocalSessionFactory.CreateSinglePlayer(...)`：4 座；0 号真人，1–3 Bot；本地回环 gateway。
- 人类输入：UI → `Command` → `GameSession.Submit` → 校验 → 事件。
- 请求：`RequestOpened` 事件带 `RequestId/DeadlineTick/AllowedVerbs`；Bot 由会话在 300ms 后自动提交。
- 事件可见性：M0.2 全本地，仍按座位过滤（自己手牌/公共区）；为 M1 流正式化保留。
- 单线程：`Step` 由客户端主循环驱动（10Hz）；会话内无锁、无静态。

## 3. 测试

- 脚本化人类输入（固定出牌）完成 8 局；4 Bot 完成 8 局。
- 两个 GameSession 交错 Step，状态/事件互不串。
- 事件 seq 单调；Drain 后不再重复；非法 Command 被拒绝且不改状态。
