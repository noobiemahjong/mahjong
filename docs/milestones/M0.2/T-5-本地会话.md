# T-5 本地会话（实施规格）

状态：见任务表
依赖：T-1、T-3、T-4
对应 master：[M0.2](../M0.2-单机可玩闭环.md)
验收：人类脚本/4 Bot 走完 8 局；事件流可消费；两会话隔离；无网络代码。

## 1. API

`Mahjong.Session`：

```csharp
public enum SessionEventKind : byte
{
    RoundStarted = 1, TurnStarted, Drew, Discarded, Meld,
    RequestOpened, RequestClosed, RoundEnded, GameEnded, SeatStateChanged,
}
public readonly record struct SessionEvent(long Seq, long Tick, SessionEventKind Kind, ReadOnlyMemory<byte> Payload);

public enum CommandVerb : byte { Discard = 1, Pong = 2, Kong = 3, Win = 4, Pass = 5 }
[Flags] public enum AllowedVerbs : ushort { None = 0, Discard = 1, Pong = 2, Kong = 4, Win = 8, Pass = 16 }
public readonly record struct Command(long ClientSeq, byte Seat, CommandVerb Verb, int Slot, ushort CardId, long RequestId);
public readonly record struct SubmitResult(bool Accepted, string? Reason, long RequestId);

public enum RequestKind : byte { Discard, Pong, Kong, Win, Pass }
public readonly record struct Request(long RequestId, byte Seat, RequestKind Kind, AllowedVerbs Allowed, long DeadlineTick);

public sealed record SessionConfig(byte HumanSeat, byte BotCount, int TickRate = 10,
    int TurnTimeoutTicks = 600, int ResponseTimeoutTicks = 150, string ContentDirectory = "content");

public sealed class GameSession
{
    public GameSession(SessionConfig config, ContentCatalog content, TableCatalog tables, IWinChecker wins, IRandomSource rng);
    public IReadOnlyList<SessionEvent> DrainEvents(byte viewerSeat); // 255 = 全景
    public void Start();
    public void Step(long tick);
    public SubmitResult Submit(Command command);
    public GameState State { get; }
    public long Tick { get; }
}
```

### 1.1 事件 payload（二进制字段，按序）

| Kind | 字段 |
|---|---|
| RoundStarted | roundNo u8、bankerSeat u8、wallCount u16、tailCount u16 |
| TurnStarted | seat u8、deadlineTick i64 |
| Drew | seat u8、tileId i32（非本人=-1）、wallCount u16、tailCount u16 |
| Discarded | seat u8、slot u16、tileId u16 |
| Meld | seat u8、kind u8、count u8、tileIds u16[count]、targetSeat u8（255=无） |
| RequestOpened | requestId i64、seat u8、kind u8、allowed u16、deadlineTick i64 |
| RequestClosed | requestId i64、outcome u8（0 应答/1 超时/2 取消）、answerLen u16、answer bytes |
| RoundEnded | winnerSeat i8（-1 流局）、scoreDelta i32[4]、actionType u16 |
| GameEnded | totalScores i32[4]、ranking u8[4] |
| SeatStateChanged | seat u8、state u8（0 Online/1 Grace/2 Bot/3 Offline） |

可见性：`DrainEvents(viewerSeat)` 在产出侧过滤——只给自己手牌/摸牌的 tileId；其他座位只给数量；255 全景不过滤。seq 从 1 单调，Drain 后不重复。

## 2. 回合流程（T-5 负责）

T-5 用 M0.1 T-5 的 Action 树实现整场流程：

```
GameStart -> for round 1..8:
  Preparing(洗牌/发牌) -> Dealing(3×4+1) -> TurnLoop:
    TurnStarted -> Draw/WallEmpty? -> SelfDrawn(check) -> Request(Discard) ->
    Discard -> ResponseWindow(碰/杠) -> (Meld? -> 补牌/强制出牌) -> next
  RoundEnded(计分/流局回滚) -> 等待全员 Ready
GameEnded
```

- 自摸在 Draw 后直接结算；弃牌响应窗口只处理碰/杠（无点炮）。
- 技能 Validate/Commit 由 T-2 提供；计分由 T-3；Bot 由 T-4；本任务只编排。
- 请求 deadline 用 tick：出牌 600 tick、响应 150 tick；Bot 300ms=3 tick 后在会话内提交。

## 3. 本地组装

- `LocalSessionFactory.CreateSinglePlayer(ContentCatalog, ...)`：4 座；0 号真人，1–3 Bot。
- 人类输入：UI → `Command` → `Submit` → 校验 → 事件；非法返回 `SubmitResult(false,...)`。
- Bot：会话在请求打开后 3 tick 调 `IBotPolicy` 并 Submit。
- 单线程：`Step` 由客户端主循环 10Hz 驱动；无锁、无静态。

## 4. 测试

- 脚本化人类输入完成 8 局；4 Bot 完成 8 局；牌数守恒。
- 两个 GameSession 交错 Step，状态/事件互不串。
- 事件 seq 单调；Drain 后不重复；非法 Command 返回 false 且不改状态。
- 同一 seed + 同脚本两遍最终 StateHash 一致。
