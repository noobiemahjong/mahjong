## 1. 计分

`Mahjong.Core.Rules.Scoring`：

````csharp
[Flags] public enum ScoreActionType : ushort
{
    SelfDrawn = 1, SevenPairs = 2, ConcealedKong = 4, ExposedKong = 8,
    KongSupplement = 16, KongUpFlower = 32, NoJoker = 64,
}
public sealed class ScoreManager
{
    public void Apply(byte seat, short delta, ScoreActionType type);
    public void Release();          // 局结束/流局时把暂存写入总分（流局前先 Rollback）
    public void RollbackRound();    // 撤回本局所有暂存
    public short[] RoundDelta { get; }
    public short[] TotalScores { get; }
}
````

公式（M0.2 子集）：

- 自摸：基础分 无鬼 4 / 有鬼 2；每家付（+base×3，others -base）；`NoJoker` 标记。
- 七对：自摸分 ×2；`SevenPairs`。
- 杠上开花：自摸分 ×2；`KongUpFlower`。
- 明杠：+3，放杠者 -3；暗杠：+6，其余各 -2；补杠：+3，其余各 -1。
- 流局：先 `RollbackRound` 撤回本局暂存，再 `Release`（净 0）；庄家不变。
- 不含：承包/抢杠/12 张/跟庄/中马（M1/M4）。

## 2. 轮次

`Mahjong.Core.Rules.RoundController`：

- 起庄随机（由注入 RNG）；每局开始洗牌/发牌；`TotalRounds = 8`。
- 局结束：赢家非庄 → 赢家坐庄；流局 → 庄家不变；分数累计。
- 8 局后按总分排序；同分按座位号稳定排序。
- 事件：`RoundStarted / TurnStarted / RoundEnded / GameEnded`（T-5 流）。

## 3. 测试

- 各番种单算；可行组合：自摸+无鬼、七对+无鬼、杠上开花（须有杠）；**七对不能与杠上开花组合**（七对须 0 副露）。杠分三方扣款；流局回滚后总分不变。
- RoundController 签名：`RoundResult RunRound(GameState, IReadOnlyList<Command>)`；8 局单元模拟能结束（不依赖 T-5）；庄家轮换正确；同分排序稳定；流局计 1 局。
