## 写入规则

- 编号连续（`001` 起），新建前先查本表避让；文件名 `NNN-短标题.md`。
- 状态取值：`草案` / `已确认` / `已废弃` / `被 ADR-xxx 收窄` / `被 ADR-xxx 替代`。
- 每条 ADR 至少包含：背景、决策、理由、放弃了什么、后果。
- 决策若变更 `docs/DESIGN.md` 的基线，必须在 ADR 中写明「收窄/替代 DESIGN §x / Dn」，并在同一提交更新 DESIGN 的决策表与 ADR 索引。
- 不在 ADR 里复述设计正文；用链接与 `Dn` 编号指向基线。
