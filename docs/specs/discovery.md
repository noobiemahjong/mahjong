# 局域网发现协议（UDP，v1）

状态：M2 实现；发现只用于“找到房间”，不承载对局数据。

## 1. 端口与报文

- UDP 固定端口 **47777**；游戏端口由应答告知。
- 请求：`MJDP` + `v1 u8` + `nonce u32`（32B 内）。
- 应答：`MJDP` + `v1` + `nonce` + u8 房间名长度 + 房间名 UTF8 + u8 房主名长度 + 房主名 UTF8 +
  `players u8` + `maxPlayers u8` + `gamePort u16` + `protocolVersion u16` + `rulesVersion u16` +
  `contentHash 32B` + `tickRate u8` + `flags u8`（bit0=有密码, bit1=对局中）。

## 2. 发现流程

1. 客户端向本机每个网段的定向广播地址与 `255.255.255.255` 发请求；
2. 服务端单播应答（不广播应答）；
3. 列表显示房间名/人数/版本/是否对局中；版本不匹配置灰；
4. 兜底：手动输入 IP、最近连接列表。

## 3. 约束

- 每秒最多 2 次请求；应答随机延迟 0–50ms 防碰撞。
- 发现不认证、不加密；只用于局域网。
- Windows 防火墙首次提示需允许；广播不跨 VLAN/Wi-Fi 隔离，失败时用手动 IP。
- 同机多开：每实例用不同游戏端口；发现端口冲突时只允许一个 responder（文档说明）。
