# 旧版行为偏离登记

> 本表登记**我们有意不等价于旧 Unity 版本**的地方。没有登记的差异 = 缺陷；登记的差异才是「设计」。
> 每行必须有：对象、旧版行为、新版行为、理由、落点（DESIGN §/Dn 或 ADR）、状态。
> 状态取值：`已登记` / `已实现` / `已验证` / `已回补`（回补=改回旧行为）。

| 编号 | 对象 | 旧版行为 | 新版行为 | 理由 | 落点 | 状态 |
|---|---|---|---|---|---|---|
| OLD-001 | 逻辑时间 | async/await + 动画时长参与节奏 | 10Hz 逻辑 tick；表现不阻塞逻辑 | 确定性/回放/重连 | D4 / §5.2 | 已登记 |
| OLD-002 | 随机与洗牌 | 服务端随机，重放依赖环境 | 服务端唯一 RNG；随机结果走 SyncValue；在线不下发 seed | 可回放、防作弊 | §5.4 | 已登记 |
| OLD-003 | 玩家输入等待 | 规则层深 await，掉线易卡死 | PendingRequest + deadline tick，超时/托管都是事件 | 可重连、可测试 | §5.3 | 已登记 |
| OLD-004 | 断线重连 | 全量重放 + 连接/规则耦合，易卡在半路 | 30s 宽限 → Bot 接管；回来立即交还；整局托管 | 朋友局体验 | D5/D6 / §10 | 已登记 |
| OLD-005 | 观战 | 无 | 身份盲只读，上限 8；全知仅私有房开关 | 防作弊 | D7 / §9 | 已登记 |
| OLD-006 | 回放 | 无 | 全景流；赛后下载；服务器保留最近 30 局；选轮/快进 | 复盘与排障 | D1/D8 / §8 | 已登记 |
| OLD-007 | 对局中入座 | 尝试支持迟到玩家 | 不允许中途入座，只允许原座位重连 | 状态一致性 | §10/§11 | 已登记 |
| OLD-008 | 主机退出/空房 | 局域网房主退出即结束 | 局域网同旧；公网服务器独立，单个玩家退出不结束；全员离线立即销毁 | 语义明确 | D13 / §11 | 已登记 |
| OLD-009 | 联机依赖 | Unity Netcode + UGS Lobby/Relay | 自研协议 + 权威服务器（VPS）；局域网 UDP 发现 | 可控/可回放/免云依赖 | D0 / §6/§11 | 已登记 |
| OLD-010 | 发布形态 | Unity IL2CPP | 客户端 net10 + NativeAOT；服务端 JIT | 启动/体积/可部署 | D12 / §3.4 | 已登记 |
| OLD-011 | 交互 | 鼠标 hover 高亮 + 甩牌 | 保留鼠标交互，同时提供触摸等价；输入抽象统一 | 移动端后续 | D18 / §7.5 | 已登记 |
| OLD-012 | 牌桌 UI | Unity uGUI + Prefab | Godot Control/Node2D，按移动端分辨率约束实现 | 引擎更换 | §7/§7.5 | 已登记 |
