# M2 实施规格

状态：未开工
对应 master：[M2 计划](M2-局域网.md)

## T-1 发现

- 服务端 `LanDiscoveryResponder`：绑定 47777，收到请求按 [discovery](../specs/discovery.md) 应答。
- 客户端 `LanDiscoveryClient`：枚举网卡 → 定向广播 + 255.255.255.255；收应答聚合。
- UI：房间列表（名称/人数/版本/状态）+ 手动 IP；选中后连 TCP 游戏端口。
- 测试：同机 responder/client 回环；版本不匹配置灰；无 responder 时超时不崩。

## T-2 传输与房主内嵌会话

- `TcpSessionHost`：`TcpListener`/`Socket` + `System.IO.Pipelines`；每连接一个读任务 + 写队列；帧解析按 [protocol](../specs/protocol.md)。客户端同用 .NET Sockets，不用 Godot `StreamPeerTCP`。
- 房主进程内起权威 `GameSession`；4 客户端接入；命令入队，tick 驱动；事件按座位过滤后广播。
- 握手校验三元组；`playerToken` 生成/保存；连接上限 4 + 观战 8。
- 网络线程只做 I/O；会话逻辑单线程；队列交接，无锁共享状态。
- 测试：本机 4 客户端伪造输入完成一局；坏帧断开；超大帧拒绝。

## T-3 重连与托管

- 断线检测：心跳 3s；座位 `Reserved(30s)`；到期 Bot 接管（T-4 M0.2）。
- 重连：`Resume(token, lastAckSeq)` → 全量重放本人流 → 补 `RequestOpened` → 恢复交互。
- 幂等：`requestId` 去重；旧连接踢掉；token 错拒绝。
- 玩家回来立即交还 Bot 控制；deadline 重置。
- 测试：30s 内重连、60s 后重连、重复命令、对局中重连。

## T-4 观战

- 无座位连接；单独 `SpectatorSlot`（上限 8）；流可见性 = 无手牌玩家。
- 中途加入：先全量重放历史流，再实时；只读，不接受 Command。
- 不影响计时/结算；房间设置可关。
- 测试：中途加入看到公开信息；手牌不可见；观战断开不影响对局。
