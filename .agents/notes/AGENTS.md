# .agents/notes/AGENTS.md

适用 `.agents/notes/**`。规则正文见 [README.md](README.md)。

- 路径必须是 `{lifecycle}/{class}/yyyy-mm-dd-slug.md`；lifecycle/class 见 README 的闭集。
- 每篇首行 `# Agent Note: <标题>`，第三行 `Status:` 且与所在文件夹一致。
- 四段必填：`## Problem` / `## Decision` / `## Alternatives considered` / `## Consequences`。
- 禁止新建 `INDEX.md` 或任何总索引。
- 非平凡改动同批写；机械/局部改动豁免。
- `implemented/` 跟事实更新；不改决策；被替代时交叉链接。
- `archived/` 永久冻结，不再作为权威。
