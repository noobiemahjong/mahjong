- RB-01 不做点炮/荣和；抢杠只抢补杠第 4 张。
- RB-02 杠分即时结算；承包只覆盖胡牌分。
- RB-03 四项变体都在 `RoundEnded.scoreDelta` 落账。
- RB-04 连庄只有庄家胡才 +streak；流局/换庄不加；表尾固定 3。
- RB-05 跟庄：非庄胡（含抢杠）庄家付一份；庄家胡不付。
- RB-06 中马用 `tile.Id`（物理牌）%4，不用 `typeId`。
- RB-07 承包只算明副露；补杠取原碰放牌者。
- RB-08 单牌墙：摸头、杠补墙尾、无预留；墙空跳过翻马。

## 2 支付与叠加口径

- 记法：`per0=(无鬼 4/有鬼 2)×(七对 ×2)`，`perK=2×per0`，`b=dealerStreakBonus[min(streak,len)-1]`，delta 按座 0–3，和恒 0。依据：[scoring §3](../../subsystems/scoring.md)。
- 位分布：一位规则（连庄/跟庄/中马/12 张）两侧同置；二位规则（抢杠、杠上开花承包）正位在赢家、负位在 payer；`RoundActionType` 取并集；关闭与 0 金额不置位；承包只重定向 payer。依据：[§1 事件·标志列](#1-规则总表)、[scoring §2](../../subsystems/scoring.md)。
- 叠加：21 对中只有 1×2、4×5 互斥；4×6、5×6 由优先级收敛到唯一承包者。中马条问答记录无编号（1C/2A/4A/5A/6A 缺 3），以 §1 规则行为准。依据：[§1 规则行](#1-规则总表)。
- 手算：庄胡 streak=2 无鬼自摸 `+15/-5/-5/-5`、赢家 1 明杠开花放杠 2 `-1/+28/-27/0`，和均 0。依据：§1 与 [scoring §3](../../subsystems/scoring.md)。

## 3 `content/rules.json` schema

锁定块（6A）：

```json
{
  "version": 1,
  "joker": { "mode": "FixedType", "typeId": 31 },
  "variants": {
    "dealerStreakBonus": [0, 1, 2, 3],
    "followingBanker": 1,
    "horseBonus": 1,
    "robbingKong": true,
    "kongFlowerContract": true,
    "twelveCardsContract": true
  }
}
```

- 加载链：`ContentPaths.Resolve` → `ContentCatalog.Load` → `ContentJsonContext`（source-gen、CamelCase、Disallow）→ `RulesDocument` → `ParseRules` → `VerifyManifest`。依据：[core](../../subsystems/core.md)。
- 顺序：`RulesDocument` 加 `Variants` → `ContentJsonContext` 加 `JsonSerializable` → `ParseRules` 校验 → `ContentCatalog.Variants` → 最后改 `content/rules.json`；否则 Disallow 直接拒。
- 缺省与校验：`variants` 或单字段缺失即关闭（数组空、数值 0、布尔 false）；`dealerStreakBonus` 长度 ≥1、每项 0–255（空数组报错），`followingBanker`/`horseBonus` 0–255，布尔项须 bool，未知字段报错；失败抛 `ContentLoadException` 带字段路径。
- `version` 保持 1，`rulesVersion` 升 2；contentHash 三处：`manifest.json` 的 `files["rules.json"]` sha256 与 `contentHash`、`ContentCatalogTests` 断言、AOT 冒烟 `CONTENT OK`，新值由 [T-5 §2](T-5-回归与收口.md#2-金标重录) 记录。
- `rulesVersion` 落点：[protocol §0](../../specs/protocol.md) 的 `ProtocolVersion` 类型不存在，M0.3 不新增，落点 = M1 补常量并改 §0。
- 旧回放：1→2 后旧 `.mjr` 按 [replay-format §5](../../specs/replay-format.md) 拒播，旧金标按 [T-5 §2](T-5-回归与收口.md#2-金标重录) 标注；M3 握手 `Reject(reason=1)` 承接。
