## 3. 「工程骨架」具体包含什么

1. `.gitattributes`（LF/二进制）、`.editorconfig`、`global.json`（SDK 10.0.x）、`Directory.Build.props`（TFM/Nullable/LangVersion/警告）。
2. `Mahjong.sln` + 5 工程：`Mahjong.Core`（Rules/Flow/Protocol/Content，无 Godot）、`Mahjong.Session`、`Mahjong.Client`（Godot.NET.Sdk/4.7.2、net10.0、PublishAot）、`Mahjong.Server`（net10 控制台）、`Mahjong.Tests`（xUnit，不引用引擎）。
3. 依赖方向：Client → Core；Server → Session → Core；Tests → 全部；Core 不反向依赖。
4. 手写 Composition Root（不引入反射容器）；日志 `Microsoft.Extensions.Logging`；配置从 `content/` 读。
5. Godot 工程：`project.godot`、`Startup` 空场景、导出预设（Windows）、AOT root（Client/Core/GodotSharp）。
6. 工具：`tools/doc-gate`（G1–G12）、commit-msg 钩子、`tools/aot-smoke`（空客户端导出+启动）。
7. 命令：`dotnet build`、`dotnet test`、`pwsh tools/doc-gate/doc-gate.ps1 -Fail`、`pwsh tools/aot-smoke/aot-smoke.ps1`。

## 4. 「内核骨架」具体包含什么

- 牌：34 种（万/筒/条各 1–9、风 4、箭 3）、每种 4 张、136 个物理 id；红中鬼牌。
- 区域：牌墙/手牌/副露/弃牌/亮牌；**区域保持插入序**；手牌展示排序在 ViewModel（T-4），流程区不排序。
- 操作：洗牌、发牌、摸牌（头/尾）、出牌、移除/移动的模型级 API。
- tick 引擎：Action 状态（Continue/WaitTicks/WaitUntil/WaitRequest/AbortParents/AbortSiblings/Complete）、调度器、命令队列、请求模型、状态哈希。
- 查表：加载 6 个 `.bytes`，提供 key→行 的只读查询接口（本阶段不做胡牌判定）。

## 6. 任务验收

### T-1 工程骨架

- `dotnet build` 0 warning；`dotnet test` 可跑；Core 无 Godot 引用（编译期/反射测试）。
- Godot 能打开空场景运行；Server 启动后正常退出；Client TFM net10 + PublishAot/root 配置齐全。

### T-2 质量底座

- 故意制造坏链接/BOM/CRLF/超预算/错误 Note 路径 → doc-gate 红；修复后绿。
- commit-msg 拒绝超 50 字标题、超 10 行 body；通过用例绿。
- CI 在 push/PR 跑构建+单测+doc-gate，无 paths 过滤。

### T-3 内容与查表

- 6 个 `.bytes` 全部加载；抽样 key（见 [TABLES](../TABLES.md)）与解码结果一致。
- contentHash 稳定；缺失/损坏内容启动报错可读。
- AOT 导出后仍能加载（不依赖反射 resolver）。

### T-4 牌与区域

- 单测覆盖：张数/排序/鬼牌归位/发牌数量/摸打/副露槽位；非法输入被拒。

### T-5 tick 引擎

- 脚本化 Action 树跑通；WaitTicks/WaitUntil/WaitRequest/Abort/Complete 各有用例。
- 同一脚本运行两遍状态哈希一致；两个会话交错 tick 不串状态；无静态可变状态。

### T-6 基线收口

- Windows 导出空客户端 AOT，独立 exe 启动成功、stderr 空。
- 记录：tick 微基准、查表冷加载耗时、AOT 启动耗时。
- 文档：`architecture.md` 骨架、`subsystems/core.md`、`subsystems/flow.md`、`cookbook/{build,run,aot-export}.md`、M0.1 结果。
