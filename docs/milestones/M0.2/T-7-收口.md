## 1. AOT 完整对局

在 M0.1 AOT 冒烟基础上：

1. 导出 Windows AOT（同 [T-6 M0.1 规格](../M0.1/T-6-基线收口.md)）。

3. 运行 `Mahjong.exe --autoplay`：4 Bot 自动 8 局，打印 `GAME OK rounds=8` 后退出 0；stderr 空。

### 偏差与裁定

| 编号 | 裁定 |
|---|---|
| D-T7-1 | `--autoplay` 落 `Startup` 启动分支，不新建场景/工程/exe；`--smoke` 零改动。 |
| D-T7-2 | `LOCAL READY` 由 `LocalGame` 首帧完整渲染后打印一次，作为 GUI 启动/可操作口径终点；`AUTOPLAY READY` 只表示会话已装配启动。 |
| D-T7-3 | 8 局总耗时 = launch → `GAME OK`（含启动与内容加载，阈值 <5000ms）；AOT 启动 = launch → `LOCAL READY`（阈值 <3000ms）。 |
| D-T7-4 | tick p99 = Continue-only 1e6 步 × 3 轮、每步两次 `Stopwatch.GetTimestamp`、各轮分位取中位，含计时开销为上界，阈值 <1ms。 |
| D-T7-5 | 内存 = 同进程连续两场 8 局（同 seed）、每 25 tick 采样 `GC.GetTotalMemory(false)` 峰值，第二场 ≤ 第一场 + (`first/4 + 4 MiB`)，仅托管堆。 |
| D-T7-6 | `subsystems/rules.md` 只承载胡牌判定；技能/校验器、响应窗口、计分留在 `core.md` §5、`flow.md` §8、`scoring.md`，rules 只链接。 |
| D-T7-7 | `subsystems/client.md` 只写当前实现的 LocalGame/Table/Input/View 与 autoplay/`LOCAL READY`，不写未实现的 Mirror。 |
| D-T7-8 | `subsystems/session.md` 本轮复核无改动（T-7 不改 Session 行为）。 |
