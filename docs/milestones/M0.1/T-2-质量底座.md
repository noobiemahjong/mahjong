## 2. doc-gate 规则（G1–G12）

扫描范围：仓库内 `*.md`；排除 `.git/`、`content/`、`lib/`、`bin/`、`obj/`、`build/`。
G12 只警告不阻断；其余红即 exit 1（`-Fail` 模式）。

| 编号 | 判定 |
|---|---|
| G1 | 相对链接可解析；跳过 `http(s)`/`mailto:`/`#`；仓外链接只报告 |
| G2 | 文件首三字节不得为 `EF BB BF` |
| G3 | 不得出现 `CR` |
| G4 | 同一表块：分隔行后的每行单元格数 = 表头；行内无未转义双竖线（代码跨度内不算） |
| G5 | 单行 ≤5000 字符 |
| G6 | `docs/milestones/README.md` 表行 ≤300 字符 |
| G7 | 每篇 ≤ `doc-budgets.json` 的 `limitBytes`；未登记文档只警告 |
| G8 | `limitBytes` 不得高于 baseline + `toleranceBytes`（默认 4096）；新增条目必须同时写 baseline |
| G9 | `tools/**/*.ps1` 与 `tools/git-hooks/*` 纯 ASCII |
| G10 | Note：路径 `.agents/notes/{lifecycle}/{class}/yyyy-mm-dd-slug.md`；lifecycle ∈ {proposed,implemented,rejected,archived}；class ∈ {feature,bug-fix,simplification,architecture,process,testing}；首行 `# Agent Note:`；`Status:` 与 lifecycle 一致；四段齐全；禁止 `INDEX.md` |
| G11 | `docs/engineering/pitfalls/` 文件名 `NNN-*.md` 连续；README 不写编号区间 |
| G12 | 非表格/代码/列表的段落须为单物理行（只警告） |

`doc-budgets.json` 至少包含根 `AGENTS.md`、`docs/AGENTS.md`、`docs/development.md`、`docs/architecture.md`、`docs/DESIGN.md`、`docs/TABLES.md`、`docs/milestones/*.md`、`.agents/notes/**/*.md`；上限取 [docs/AGENTS.md](../../AGENTS.md) 预算表。baseline 与 json 同步。

样例：

```json
{ "version": 1, "toleranceBytes": 4096, "limits": [ { "path": "AGENTS.md", "limitBytes": 6144 }, { "path": "docs/AGENTS.md", "limitBytes": 6144 } ] }
```

`doc-budgets-baseline.txt` 每行 `path\tlimitBytes`；G8 用 baseline 判“提额”，json 是当前值。

违规夹具：`tools/doc-gate/tests/` 下建坏链接/BOM/CRLF/超预算/错 Note/重复 pitfall 编号各一例；`doc-gate.ps1 -Fail` 必须红，修复后绿。

## 3. commit-msg 钩子

- 路径：`tools/git-hooks/commit-msg`；安装：`git config core.hooksPath tools/git-hooks`。
- 规则：首行匹配 `^(feat|fix|docs|refactor|chore|test|perf|build|ci)(\(.+\))?: .{1,50}$`；正文非空行 ≤10；空行不计。违规 exit 1 并打印原因。
- 测试：好/坏 commit message 各 2 条夹具。
- 产物树补 `tools/doc-gate/tests/` 与 `fixtures/`。

## 4. CI

`.github/workflows/ci.yml`：

- `on: push, pull_request`（不加 `paths:`）。
- `runs-on: windows-latest`；`setup-dotnet` 10.0.x。
- 步骤：restore → build → test → doc-gate（`pwsh -File tools/doc-gate/doc-gate.ps1 -Fail`）。
- 设置 `git config core.hooksPath tools/git-hooks`（让钩子测试可跑）。
- 失败即红；不跳过测试。

## 5. 验收

1. 造 6 类违规 → 对应 G 红；修复 → 绿。
2. 钩子拒绝坏标题/超长 body；好消息通过。
3. CI 在 push/PR 全绿；改文档的提交也会跑。
4. doc-gate 自身纯 ASCII（G9），退出码稳定。
