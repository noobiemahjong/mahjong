# T-4 牌与区域模型（实施规格）

状态：未开工
依赖：T-3
对应 master：[M0.1](../M0.1-工程底座与内核骨架.md)
验收：模型单测全绿；不变量可验证；无 UI/网络依赖。

## 1. 命名空间

`Mahjong.Core.Rules`（模型）；`Mahjong.Core.Content`（定义）；不引用 Godot/网络/时钟。

## 2. 类型

````csharp
public enum SuitType : byte { Character = 1, Dot = 2, Bamboo = 3, Wind = 4, Dragon = 5 }
public readonly record struct TileType(ushort Id, SuitType Suit, byte Rank);
public readonly record struct Tile(ushort Id, TileType Type) { public const ushort UnknownId = 0; }
public enum ZoneKind : byte { Wall, WallTail, Hand, Meld, Discard, Revealed }
public readonly record struct ZoneId(byte Seat, ZoneKind Kind); // Seat=255 表示公共区
public sealed class TileZone { ... }
public sealed class Meld { MeldKind Kind; Tile[] Tiles; bool Opened; byte TargetSeat; }
public enum MeldKind : byte { Pong, KongExposed, KongConcealed, KongSupplement }
public sealed class PlayerState { byte Seat; TileZone Hand; List<Meld> Melds; TileZone Discards; short Score; ... }
public sealed class GameState { TileZone Wall; TileZone WallTail; PlayerState[] Players; byte CurrentSeat; ... }
````

## 3. 不变量与 API

- `TileType` 相等只比 `Id`；`Tile` 相等只比 `Id`；id 1–136 唯一，0 仅 Unknown。
- `TileZone`：
  - `Count`、`this[int]`、`Insert(int, Tile)`、`RemoveAt(int)`、`Remove(Tile)`、`IndexOf(Tile)`、`Clear()`、`IReadOnlyList<Tile> Items`。
  - **索引即插入序**；不得在 zone 内排序；展示排序由 ViewModel 做。
  - 越界/重复 id/不存在 → 抛 `InvalidOperationException`。
- `PlayerState`：手牌 Zone、副露 List、弃牌 Zone、分数、是否庄家、状态；不提供排序 API。
- `GameState`：牌墙（头摸）、牌尾（杠补）、四玩家、当前座位、回合/局数；`Deal` 发牌 13 张/家、庄家 14 张。
- 洗牌：注入 `IRandomSource`，种子显式传入；同 seed 同结果。
  `public interface IRandomSource { uint NextUInt(); }`；PCG32 实现放 `Mahjong.Core.Rules`，状态为实例字段，禁止静态。
- 手牌展示排序：单独静态方法 `HandOrdering.SortedForDisplay(IEnumerable<Tile>)`，规则：普通牌按 Type.Id，鬼牌最后；不改 zone。
- 发牌后牌墙剩余 = 136 - 4*13 - 1（庄家多一张）= 83。

## 4. 测试

- 张数/唯一性/发牌数量/摸打/插入移除/越界/重复 id。
- 同 seed 洗牌两次一致；不同 seed 不同。
- 展示排序不改变原 zone 顺序。
- 模型层无静态可变字段（由 T-5 的 no-static 测试覆盖）。
