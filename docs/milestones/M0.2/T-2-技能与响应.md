# T-2 技能与响应窗口（实施规格）

状态：见任务表
依赖：[T-1](T-1-胡牌与七对.md)
对应 master：[M0.2](../M0.2-单机可玩闭环.md)
验收：碰/三种杠/自摸/七对动作合法；响应优先级与仲裁正确。

## 1. API

````csharp
public enum SkillId : uint { Pong = 1, Kong = 2, SelfDrawn = 3, SelfDrawnWith7Pairs = 4 }
public sealed class SkillContext
{
    public GameState State { get; }
    public PlayerState Source { get; }
    public Tile? TargetCard { get; }      // 弃牌响应时的目标牌
    public Tile? DrawnTile { get; }       // 自摸/补杠时的牌
    public byte TargetSeat { get; }       // 255=无
    public long RequestId { get; }
}
public abstract class Skill
{
    public abstract SkillId Id { get; }
    public abstract bool Validate(SkillContext context);
    public abstract void Commit(SkillContext context);
}
public interface ICardAndSkillVerifier
{
    bool Verify(GameState state, PlayerState player, SkillId? skill, Tile? card, Tile? targetCard);
}
public sealed class ResponseWindow
{
    public void Open(Tile discard, IReadOnlyList<PlayerState> candidates);
    public bool TrySubmit(PlayerState player, SkillId skill, long arrivalSeq);
    public ResponseResult? Result { get; }
}
````

## 2. 规则

- **碰**：手牌同 `Type` 非鬼牌 ≥2；取 2 张 + 目标弃牌组成 `MeldKind.Pong`；杠后/碰后强制出牌。
- **明杠**：手牌同 Type 非鬼 =3 + 目标弃牌；`KongExposed`；补牌。
- **暗杠**：手牌同 Type 非鬼 =4；`KongConcealed`；补牌。
- **补杠**：已有 `Pong` 且手牌第 4 张；`KongSupplement`；补牌。
- **自摸**：`IWinChecker.IsWin`；`SelfDrawnWith7Pairs` 优先于普通自摸（七对倍数 ×2）。
- **过**：不提交；窗口按超时/全体响应结束。
- 响应优先级：**杠 > 碰**；同优先级按 `arrivalSeq` 升序，先到先得；结果写入事件流（本地也走同一路径）。
- **无点炮/荣和**：胡只在摸牌后自摸（含七对/杠后自摸），不进入弃牌响应窗口。
- 杠补牌从牌尾取；Wall 为空即流局（WallTail 只用于杠补）。
- 鬼牌不可打出/不可作为碰杠材料（除胡牌判定）。
- 响应窗口 deadline：默认 150 tick（15s（10Hz））；到期未响应视为过。
- 牌墙：Wall=69、WallTail=14；杠从 WallTail 尾取，Wall 空且 tail 空 → 流局。

## 3. 校验器

- `Verify` 必须同时检查：座位合法、牌在手中、张数、是否鬼牌、目标牌存在、技能 Validate。
- 服务端/本地会话对每个提交动作**再校验一次**；失败不改变状态并记日志。

## 4. 测试

- 碰/明杠/暗杠/补杠/自摸/七对/过 各一例；非法动作被拒。
- 三家同时可碰/杠：杠优先；同优先级先到先得；败者收到取消。
- 自摸不走响应窗口；弃牌后无人可响应则下家摸牌。
- 碰后强制出牌；杠后补牌来自牌尾；牌墙空流局。
