## 4. 规则子集（本阶段验收口径）

### 4.1 牌与区域

- 34 种牌、每种 4 张、136 id；鬼牌由 `content/rules.json` 指定（v1 默认红中）；区域保持插入序，手牌展示排序在 ViewModel。
- 区域：牌墙/手牌/副露/弃牌/亮牌；槽位插入序。

### 4.2 动作与技能

| 动作 | 要求 |
|---|---|
| 摸牌/出牌 | 牌墙头摸、尾补；手牌合法性校验 |
| 碰 | 手牌 2 张同 Type 非鬼 + 目标弃牌；碰后强制出牌 |
| 明杠 | 手牌 3 张同 Type 非鬼 + 目标弃牌 |
| 暗杠 | 手牌 4 张同 Type 非鬼 |
| 补杠 | 已有碰的 3 张 + 手牌第 4 张 |
| 自摸 | 胡牌表判定（含鬼），结算 |
| 七对 | 独立判定，倍数 ×2 |
| 过 | 响应窗口放弃 |
| 流局 | 牌墙空即流局（单牌墙，无预留牌尾） |

响应窗口只处理弃牌响应：**杠 > 碰**；同一 tick 内多个合法响应按座位号升序，跨 tick 先到先得，结果写入流。

> **本阶段无点炮/荣和**：胡只有自摸（含七对、杠后自摸）；胡不参与弃牌响应窗口。这是与旧版 4 技能一致的口径；抢杠在 M0.3（只抢补杠牌）。


### 4.3 计分与轮次

- 自摸：无鬼 4 / 有鬼 2（每家付）；七对 ×2；杠上开花 ×2。
- 杠：明杠 +3/放杠者 -3；暗杠 +6/其余各 -2；补杠 +3/其余各 -1。
- 流局：本局分数回滚。
- 8 局；随机起庄；庄家首回合摸第 14 张（发牌 13 张）；非庄胡牌则赢家坐庄，庄家胡/流局连庄；M0.2 内庄家不改分数（变体在 M0.3）；终局总分/名次。
- **不含**：连庄奖励/承包/抢杠/12 张/跟庄/中马（[M0.3 规则完整化](M0.3-规则完整化.md)）。

### 4.4 Bot

- 能胡则胡；能碰/杠按简单规则；出牌优先摸到的牌，否则第一张合法牌。
- 不接 AI 牌效表；会话层固定 300ms；同 seed 决策一致。

## 6. 任务验收

### T-1 胡牌/七对

- 胡/不胡/七对/鬼牌补齐/多解牌型金标用例；与旧表解码结果一致。

### T-1b 单牌墙与发牌修正

- Wall 84、四家各 13、庄家首回合摸后 14/83；无 WallTail；StateHash/事件/金标更新；T-1 测试无回退。

### T-2 技能与响应

- 杠优先于碰；非法碰/杠被拒；碰后强制出牌；同一 tick 内多个响应按**座位号升序**，跨 tick 先到先得；自摸在摸牌阶段结算，不进入响应窗口。

### T-3 计分与轮次

- 自摸/七对/三种杠/流局回滚/庄家轮换/8 局结束用例；分数与手算一致。

### T-4 Bot

- 单次决策合法、无非法动作、同 seed 一致、单次 <1ms；4 Bot 8 局集成验收归 T-5。

### T-5 本地会话

- 脚本化人类输入走完 8 局；4 Bot 走完；两个会话交错状态隔离；事件流可被客户端消费；无网络代码。

### T-6 Godot 最小闭环

手工清单全过：

1. 启动 → 本地对局 → 发牌 → 轮流出牌。
2. 看到：自己手牌、四家弃牌/副露、剩余牌数、分数、当前轮到谁。
3. 操作：出牌/碰/杠/胡/过；非法操作不可点。
4. 一局结算；8 局总分/名次；返回/重开。
5. 连续两局无崩溃、无卡死、无控制台红字。

### T-7 收口

- Windows AOT 独立 exe 完成一局；stderr 空；启动到可操作 <3s。
- 性能基线：tick p99、8 局逻辑模拟耗时、AOT 启动耗时。
- 文档：architecture 更新；rules/session/client 页；cookbook play；M0.2 结果与已知缺口。
- 代码无未登记 TODO；缺口列去向。

## 7. M0.2 完成定义（全部满足）

1. 1 真人 + 3 Bot 完成 8 局（规则子集），结算/重开正常；手工清单全过。
2. 4 Bot 8 局自动完成；同 seed 两次最终状态哈希一致；关键规则用例覆盖。
3. AOT 独立 exe 完成一局；stderr 空；启动 <3s（开发机）。
4. 10Hz 下 tick p99 <1ms；8 局逻辑模拟 <5s；连续两局无内存持续增长。
5. 文档：architecture、rules/session/client 子系统页、cookbook play、M0.2 结果/缺口。
6. 范围守门：未把网络/回放/观战/移动端混进本阶段；规则变体在 M0.3。
