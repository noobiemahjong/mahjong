## 1. 目标

一句话：**把「能长期开发」的底座一次建好：5 个工程、构建/测试/AOT/CI/doc-gate、内容与查表、牌/区域模型、tick 引擎。** 本阶段结束时还没有可玩的牌局，但换一个人能按文档把工程跑起来、跑测试、导出 AOT、看懂内核结构。

## 3. 「工程骨架」具体包含什么

1. `.gitattributes`（LF/二进制）、`.editorconfig`、`global.json`（SDK `10.0.401` + `rollForward: latestPatch`）、`Directory.Build.props`（TFM/Nullable/LangVersion/警告）、`Directory.Packages.props`（CPM 集中管 Core/Session/Server/Tests 的包版本；`Mahjong.Client` 设 `ManagePackageVersionsCentrally=false`，Godot.NET.Sdk 注入带 Version 的隐式 GodotSharp 引用，与 CPM 冲突）。
2. `Mahjong.sln` + 5 工程：`Mahjong.Core`（Rules/Flow/Protocol/Content，无 Godot）、`Mahjong.Session`、`Mahjong.Client`（Godot.NET.Sdk/4.7.2、net10.0、PublishAot）、`Mahjong.Server`（net10 控制台）、`Mahjong.Tests`（xUnit，不引用引擎）。
3. 依赖方向：Client → Session → Core；Server → Session → Core；Tests → Core/Session（不引用 Godot/Client）；Core 不反向依赖。
4. 手写 Composition Root（不引入反射容器）；日志 `Microsoft.Extensions.Logging`；配置从 `content/` 读。
5. Godot 工程：`project.godot`、`Startup` 空场景、导出预设（Windows）、AOT root（Client/Session/Core/GodotSharp）。
6. 工具：`tools/doc-gate`（G1–G12）、commit-msg 钩子、`tools/aot-smoke`（空客户端导出+启动）。
7. 命令：`dotnet build`、`dotnet test`、`pwsh tools/doc-gate/doc-gate.ps1 -Fail`、`pwsh tools/aot-smoke/aot-smoke.ps1`。

## 4. 「内核骨架」具体包含什么

- 牌：34 种（万/筒/条各 1–9、风 4、箭 3）、每种 4 张、136 个物理 id；鬼牌由 `content/rules.json` 指定（v1 默认红中，支持 None）；**当前鬼牌不进 rank 计数**，只作万能牌。
- 区域：牌墙/手牌/副露/弃牌/亮牌；**区域保持插入序**；手牌展示排序在 ViewModel（T-4），流程区不排序。
- 操作：洗牌、发牌、摸牌（头/尾）、出牌、移除/移动的模型级 API。
- tick 引擎：Action 状态（Continue/WaitTicks/WaitUntil/WaitRequest/AbortParents/AbortSiblings/Complete）、调度器、命令队列、请求模型、状态哈希。
- 查表：加载 6 个 `.bytes`，提供 key→行 的只读查询接口（本阶段不做胡牌判定）。

## 结果

日期：2026-10-29

做了什么：AOT 空客户端导出与冒烟管线（`tools/aot-smoke`）加 `Startup` 冒烟内容加载；三项性能基线（tick / 查表冷加载 / AOT 启动）；[architecture](../architecture.md) 重写与 [core](../subsystems/core.md)、[flow](../subsystems/flow.md) 子系统页；[cookbook/build](../cookbook/build.md)、[cookbook/run](../cookbook/run.md)、[cookbook/aot-export](../cookbook/aot-export.md)；[godot-aot](../reference/godot-aot.md) 按本机复现事实更新；本阶段任务表与文档收口。

与计划的差异：导出链路需要 `project.godot` 的 `dotnet/project/solution_directory` 与 `Mahjong.Client.csproj` 的 `WarningsNotAsErrors=IL2104;IL3053`；导出数据目录按 `assembly_name` 命名为 `data_Mahjong.Client_windows_x86_64/`；导出版固定向 stderr 写两行引擎证书库错误，冒烟改为逐行白名单；AOT 只验证 Windows。逐条裁定见 [T-6 实施记录](M0.1/T-6-基线收口.md) 的「偏差」。

证据与复现：`dotnet build Mahjong.sln -warnaserror` 0 警告 0 错误；`dotnet test Mahjong.sln` 436 通过；`pwsh -NoProfile -File tools/doc-gate/doc-gate.ps1 -Fail` 88 files / 0 errors；`pwsh -NoProfile -File tools/aot-smoke/aot-smoke.ps1` exit 0，日志 `build/aot-smoke.log`、`build/aot-smoke-export.log`、`build/aot-smoke-run.log`。

基线（开发机 Intel Core i7-9700，8 核 8 线程 3.00 GHz，31.8 GiB，Windows 10 专业版；采样时并行构建与 AOT 导出，CPU 负载 2%–31%）：
